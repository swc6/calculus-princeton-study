第10周：练习题目

第一类换元积分法（凑微分法）

选择题

  • $\int 3x^2 e^{x^3} dx$ 等于：

A. $e^{x^3} + C$

B. $e^{x^3} + C$

C. $3e^{x^3} + C$

D. $\frac{1}{3}e^{x^3} + C$

  • $\int \frac{dx}{x \ln x}$ 等于：

A. $\ln|\ln x| + C$

B. $\frac{1}{\ln x} + C$

C. $\ln x + C$

D. $\frac{1}{x} + C$

  • $\int \sin^3 x \cos x dx$ 等于：

A. $\frac{\sin^4 x}{4} + C$

B. $\frac{\sin^3 x}{3} + C$

C. $\frac{\cos^4 x}{4} + C$

D. $\cos^3 x + C$

填空题

  • $\int \frac{dx}{\sqrt{1 - x^2}} = $ __________。
  • $\int \frac{x dx}{1 + x^2} = $ __________。
  • $\int \sec^2 x dx = $ __________。
  • $\int \csc^2 x dx = $ __________。
  • $\int \frac{e^x dx}{1 + e^x} = $ __________。

解答题

  • 计算 $\int \frac{(\ln x)^2}{x} dx$。
  • 计算 $\int \tan x dx$。
  • 计算 $\int \frac{dx}{a^2 - x^2}$（$a > 0$）。
  • 计算 $\int \sin^2 x dx$。

第二类换元积分法

选择题

  • 对于 $\int \sqrt{a^2 - x^2} dx$，应令：

A. $x = a \tan t$

B. $x = a \sin t$

C. $x = a \sec t$

D. $x = a \cos t$

  • $\int \frac{dx}{\sqrt{x^2 + a^2}}$ 等于：

A. $\arcsin \frac{x}{a} + C$

B. $\ln|x + \sqrt{x^2 + a^2}| + C$

C. $\ln|x + \sqrt{x^2 - a^2}| + C$

D. $\arctan \frac{x}{a} + C$

  • 对于 $\int \sqrt{x^2 - a^2} dx$，应令：

A. $x = a \sin t$

B. $x = a \tan t$

C. $x = a \sec t$

D. $x = a \cos t$

填空题

  • $\int \frac{dx}{\sqrt{4 - x^2}} = $ __________。
  • $\int \frac{dx}{\sqrt{x^2 + 9}} = $ __________。
  • $\int \sqrt{1 - x^2} dx = $ __________。
  • $\int \sqrt{x^2 + 4} dx = $ __________。

解答题

  • 计算 $\int \frac{dx}{\sqrt{x^2 - 4}}$（$x > 2$）。
  • 计算 $\int x \sqrt{a^2 - x^2} dx$（$a > 0$）。
  • 计算 $\int \frac{x^2 dx}{\sqrt{a^2 - x^2}}$（$a > 0$）。

综合应用

选择题

  • $\int \frac{x + 1}{x^2 + 2x + 5} dx$ 等于：

A. $\frac{1}{2} \ln(x^2 + 2x + 5) + C$

B. $\ln(x^2 + 2x + 5) + C$

C. $2\ln(x^2 + 2x + 5) + C$

D. $\frac{x^2}{2} + x + 5x + C$

  • $\int \frac{dx}{x^2 + 4x + 5}$ 等于：

A. $\arctan(x + 2) + C$

B. $\ln(x^2 + 4x + 5) + C$

C. $\frac{1}{x + 2} + C$

D. $\arcsin(x + 2) + C$

填空题

  • $\int \frac{dx}{1 + e^x} = $ __________。
  • $\int \frac{e^x - 1}{e^x + 1} dx = $ __________。
  • $\int \frac{\sin x}{\cos^3 x} dx = $ __________。

解答题

  • 计算 $\int \frac{x^3}{1 + x^2} dx$。
  • 计算 $\int \frac{dx}{x^2 - 4x + 5}$。
  • 计算 $\int \sin^4 x dx$。
  • 计算 $\int \cos^3 x dx$。
  • 计算 $\int \frac{dx}{\sin x}$。
