# 第10周：积分的应用

## 学习目标
- 掌握两条曲线围成图形面积的计算方法
- 掌握旋转体体积的圆盘法、垫圈法与柱壳法
- 学会计算已知截面面积的立体体积
- 掌握平面曲线弧长的计算公式
- 学会计算旋转曲面的面积

## 学习内容

### 1. 曲线间面积的计算

#### 1.1 基本公式
由曲线 $y = f(x)$ 与 $y = g(x)$（在 $[a, b]$ 上 $f(x) \geq g(x)$）及直线 $x = a$、$x = b$ 围成图形的面积为：
$$A = \int_a^b [f(x) - g(x)] dx$$

一般情形（上下位置可能交换）：
$$A = \int_a^b |f(x) - g(x)| dx$$

解题步骤：
1. 求两曲线的交点，确定积分区间；
2. 判断区间内谁上谁下（必要时分段）；
3. 用上面的公式计算。

若曲线用 $x$ 表示为 $y$ 的函数更方便，则对 $y$ 积分：设 $x = f(y)$ 与 $x = g(y)$（在 $[c, d]$ 上 $f(y) \geq g(y)$），则：
$$A = \int_c^d [f(y) - g(y)] dy$$

#### 1.2 典型例题

例：求曲线 $y = x^2$ 与 $y = x$ 围成图形的面积。
- 求交点：$x^2 = x$，即 $x(x - 1) = 0$，得 $x = 0$ 或 $x = 1$；
- 在 $[0, 1]$ 上 $x \geq x^2$；
- $A = \int_0^1 (x - x^2) dx = \left[\frac{x^2}{2} - \frac{x^3}{3}\right]_0^1 = \frac{1}{2} - \frac{1}{3} = \frac{1}{6}$

例：求曲线 $y = \sin x$ 与 $y = \cos x$ 在 $[0, \pi]$ 上围成图形的面积。
- 交点：$\sin x = \cos x$，得 $x = \frac{\pi}{4}$；
- 在 $[0, \frac{\pi}{4}]$ 上 $\cos x \geq \sin x$；在 $[\frac{\pi}{4}, \pi]$ 上 $\sin x \geq \cos x$；
- $A = \int_0^{\pi/4} (\cos x - \sin x) dx + \int_{\pi/4}^{\pi} (\sin x - \cos x) dx$
- 第一段 $= [\sin x + \cos x]_0^{\pi/4} = \sqrt{2} - 1$；第二段 $= [-\cos x - \sin x]_{\pi/4}^{\pi} = 1 + \sqrt{2}$
- $A = (\sqrt{2} - 1) + (1 + \sqrt{2}) = 2\sqrt{2}$

### 2. 旋转体的体积

#### 2.1 圆盘法
曲线 $y = f(x) \geq 0$ 与 $x$ 轴在 $[a, b]$ 之间围成的区域绕 $x$ 轴旋转一周，所得立体的体积为：
$$V = \pi \int_a^b [f(x)]^2 dx$$
原理：在 $x$ 处垂直于 $x$ 轴切一片，截面是半径为 $f(x)$ 的圆，面积 $A(x) = \pi [f(x)]^2$。

#### 2.2 垫圈法
若区域由 $f(x) \geq g(x) \geq 0$ 在 $[a, b]$ 之间围成，绕 $x$ 轴旋转，截面是外半径 $f(x)$、内半径 $g(x)$ 的垫圈：
$$V = \pi \int_a^b \left\{[f(x)]^2 - [g(x)]^2\right\} dx$$

绕 $y$ 轴旋转时，把曲线写成 $x = g(y)$，对 $y$ 积分：
$$V = \pi \int_c^d \left\{[f(y)]^2 - [g(y)]^2\right\} dy$$

#### 2.3 柱壳法
区域由 $0 \leq g(x) \leq f(x)$ 与 $x = a$、$x = b$ 围成（$0 \leq a < b$），绕 $y$ 轴旋转时，用竖直细条卷成的薄柱壳计算更方便：
$$V = 2\pi \int_a^b x [f(x) - g(x)] dx$$
原理：在 $x$ 处取高为 $f(x) - g(x)$、厚为 $dx$ 的竖条，绕 $y$ 轴展开成薄壳，体积约为 $2\pi x [f(x) - g(x)] dx$。

一般地：绕 $y$ 轴用柱壳法时，被积函数为 $2\pi \times (\text{半径 } x) \times (\text{高度})$；绕 $x$ 轴用水平柱壳时为 $2\pi y \times (\text{宽度})$。

#### 2.4 典型例题

例（圆盘法）：求 $y = \sqrt{x}$ 与 $x$ 轴在 $[0, 4]$ 之间围成的区域绕 $x$ 轴旋转的体积。
- $V = \pi \int_0^4 (\sqrt{x})^2 dx = \pi \int_0^4 x dx = \pi \left[\frac{x^2}{2}\right]_0^4 = 8\pi$

例（垫圈法）：求 $y = x^2$ 与 $y = \sqrt{x}$ 围成的区域绕 $x$ 轴旋转的体积。
- 交点：$x^2 = \sqrt{x}$，得 $x = 0$ 或 $x = 1$，在 $[0, 1]$ 上 $\sqrt{x} \geq x^2$；
- $V = \pi \int_0^1 \left[(\sqrt{x})^2 - (x^2)^2\right] dx = \pi \int_0^1 (x - x^4) dx = \pi \left(\frac{1}{2} - \frac{1}{5}\right) = \frac{3\pi}{10}$

例（柱壳法）：求 $y = x$ 与 $y = x^2$ 围成的区域绕 $y$ 轴旋转的体积。
- 交点为 $(0, 0)$ 与 $(1, 1)$，在 $[0, 1]$ 上 $x \geq x^2$；
- $V = 2\pi \int_0^1 x (x - x^2) dx = 2\pi \int_0^1 (x^2 - x^3) dx = 2\pi \left(\frac{1}{3} - \frac{1}{4}\right) = \frac{\pi}{6}$

例（两种方法对照）：求由 $y = x^2$、$x = 2$ 与 $y = 0$ 围成的区域绕 $y$ 轴旋转的体积。
- 柱壳法：$V = 2\pi \int_0^2 x \cdot x^2 dx = 2\pi \left[\frac{x^4}{4}\right]_0^2 = 8\pi$
- 垫圈法（对 $y$ 积分，$x = \sqrt{y}$，$y \in [0, 4]$）：$V = \pi \int_0^4 (\sqrt{y})^2 dy = \pi \int_0^4 y dy = 8\pi$
- 两种方法结果一致，可互相验证。

### 3. 已知截面面积的立体体积

#### 3.1 一般公式
若立体被垂直于 $x$ 轴的平面所截，截面面积为已知的连续函数 $A(x)$（$a \leq x \leq b$），则体积为：
$$V = \int_a^b A(x) dx$$
旋转体体积是它的特例（$A(x) = \pi [f(x)]^2$ 等）。

#### 3.2 典型例题

例：某立体的底面是由 $y = 0$、$y = x$ 与 $x = 1$ 围成的三角形，垂直于 $x$ 轴的截面都是正方形，求其体积。
- 在 $x$ 处底边长为 $x$，故截面正方形面积 $A(x) = x^2$；
- $V = \int_0^1 x^2 dx = \frac{1}{3}$

例：某立体的底面是半径为 1 的圆 $x^2 + y^2 = 1$，垂直于 $x$ 轴的截面都是等边三角形，求其体积。
- 在 $x$ 处底边长为 $2\sqrt{1 - x^2}$，等边三角形面积 $A(x) = \frac{\sqrt{3}}{4} \cdot 4(1 - x^2) = \sqrt{3}(1 - x^2)$；
- $V = \int_{-1}^1 \sqrt{3}(1 - x^2) dx = \sqrt{3}\left[x - \frac{x^3}{3}\right]_{-1}^1 = \sqrt{3} \cdot \frac{4}{3} = \frac{4\sqrt{3}}{3}$

### 4. 弧长

#### 4.1 基本公式
曲线 $y = f(x)$ 在 $[a, b]$ 上的弧长为：
$$L = \int_a^b \sqrt{1 + [f'(x)]^2} dx$$
原理：把曲线分成小段，每段长约为 $\sqrt{(dx)^2 + (dy)^2} = \sqrt{1 + [f'(x)]^2}\, dx$。

参数曲线 $x = x(t)$，$y = y(t)$（$\alpha \leq t \leq \beta$）的弧长为：
$$L = \int_\alpha^\beta \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2} dt$$

#### 4.2 典型例题

例：求曲线 $y = \frac{2}{3} x^{3/2}$ 在 $[0, 3]$ 上的弧长。
- $f'(x) = \sqrt{x}$，$1 + [f'(x)]^2 = 1 + x$；
- $L = \int_0^3 \sqrt{1 + x}\, dx = \left[\frac{2}{3}(1 + x)^{3/2}\right]_0^3 = \frac{2}{3}(8 - 1) = \frac{14}{3}$

例：求曲线 $y = \frac{x^2}{2}$ 在 $[0, 1]$ 上的弧长。
- $f'(x) = x$，$L = \int_0^1 \sqrt{1 + x^2}\, dx$；
- 利用公式 $\int \sqrt{1 + x^2}\, dx = \frac{x}{2}\sqrt{1 + x^2} + \frac{1}{2}\ln(x + \sqrt{1 + x^2})$；
- $L = \frac{\sqrt{2}}{2} + \frac{1}{2}\ln(1 + \sqrt{2})$

例：求曲线 $y = \ln(\sec x)$ 在 $[0, \frac{\pi}{4}]$ 上的弧长。
- $f'(x) = \tan x$，$\sqrt{1 + \tan^2 x} = \sec x$（区间上为正）；
- $L = \int_0^{\pi/4} \sec x\, dx = \left[\ln|\sec x + \tan x|\right]_0^{\pi/4} = \ln(1 + \sqrt{2})$

### 5. 旋转曲面的面积

#### 5.1 基本公式
曲线 $y = f(x) \geq 0$ 在 $[a, b]$ 上绕 $x$ 轴旋转所得曲面的面积为：
$$S = 2\pi \int_a^b f(x) \sqrt{1 + [f'(x)]^2}\, dx$$

绕 $y$ 轴旋转（$0 \leq a < b$）时：
$$S = 2\pi \int_a^b x \sqrt{1 + [f'(x)]^2}\, dx$$

记忆方式：旋转曲面面积微元为"周长 × 弧长微元"：$dS = 2\pi(\text{半径}) \cdot ds$，其中 $ds = \sqrt{1 + [f'(x)]^2}\, dx$。注意与旋转体体积区分：体积微元是"圆盘面积 × 厚度"，半径只用 $f(x)$；曲面面积中根号里的 $f'(x)$ 不能省略。

#### 5.2 典型例题

例：求半径为 $r$ 的球的表面积。
- 上半圆 $y = \sqrt{r^2 - x^2}$，$y' = \frac{-x}{\sqrt{r^2 - x^2}}$；
- $\sqrt{1 + (y')^2} = \sqrt{1 + \frac{x^2}{r^2 - x^2}} = \frac{r}{\sqrt{r^2 - x^2}}$；
- $f(x)\sqrt{1 + (y')^2} = \sqrt{r^2 - x^2} \cdot \frac{r}{\sqrt{r^2 - x^2}} = r$；
- $S = 2\pi \int_{-r}^r r\, dx = 2\pi r \cdot 2r = 4\pi r^2$

例：求 $y = x^2$ 在 $[0, 1]$ 上绕 $y$ 轴旋转所得曲面的面积。
- $y' = 2x$，$S = 2\pi \int_0^1 x \sqrt{1 + 4x^2}\, dx$；
- 令 $u = 1 + 4x^2$，$du = 8x\, dx$，则 $\int x\sqrt{1 + 4x^2}\, dx = \frac{1}{12}(1 + 4x^2)^{3/2}$；
- $S = 2\pi \cdot \frac{1}{12}\left[(1 + 4x^2)^{3/2}\right]_0^1 = \frac{\pi}{6}(5\sqrt{5} - 1)$

## 学习建议
- 求面积前先画草图，确定交点并判断谁上谁下，交点改变上下关系时要分段积分
- 求旋转体体积时先确认旋转轴：绕 $x$ 轴常对 $x$ 积分，绕 $y$ 轴可选用柱壳法避免解出反函数
- 柱壳法微元为 $2\pi \times$（旋转半径）$\times$（母线高度）$\times\, dx$，与圆盘法微元 $\pi \times$（半径平方）$\times\, dx$ 不要混淆
- 已知截面面积的立体体积问题，关键是把截面边长用 $x$ 表示，再代入相应面积公式
- 弧长与旋转曲面面积公式中的根号往往能凑成完全平方或用换元化简，注意积累 $\sqrt{1+x^2}$、$\sec x$ 等常见积分
- 计算结果可用两种方法（如柱壳法与垫圈法）互相对照检验
