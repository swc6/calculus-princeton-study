第10周：换元积分法

学习目标

  • 掌握第一类换元积分法（凑微分法）
  • 掌握第二类换元积分法
  • 学会选择合适的换元方法
  • 能够熟练运用换元法计算不定积分
  • 理解换元法在定积分中的应用

学习内容

1. 第一类换元积分法（凑微分法）

1.1 基本原理

第一类换元积分法的核心思想是将复杂的积分通过变量代换转化为基本积分公式的形式。

如果 $\int f(u) du = F(u) + C$，且 $u = g(x)$ 可导，则：

$$\int f(g(x)) g'(x) dx = \int f(u) du = F(u) + C = F(g(x)) + C$$

1.2 常见的凑微分形式

  • $dx = \frac{1}{a} d(ax + b)$
  • $x dx = \frac{1}{2} d(x^2)$
  • $\sin x dx = -d(\cos x)$
  • $\cos x dx = d(\sin x)$
  • $\frac{dx}{x} = d(\ln|x|)$
  • $\frac{dx}{\cos^2 x} = d(\tan x)$
  • $e^x dx = d(e^x)$

1.3 典型例题

  • $\int 2x e^{x^2} dx$

- 凑微分：$d(x^2) = 2x dx$

- 原式$= \int e^{x^2} d(x^2) = e^{x^2} + C$

  • $\int \frac{\ln x}{x} dx$

- 凑微分：$\frac{dx}{x} = d(\ln x)$

- 原式$= \int \ln x d(\ln x) = \frac{1}{2} (\ln x)^2 + C$

  • $\int \tan x dx$

- 原式$= \int \frac{\sin x}{\cos x} dx = -\int \frac{d(\cos x)}{\cos x} = -\ln|\cos x| + C = \ln|\sec x| + C$

  • $\int \frac{dx}{a^2 + x^2}$

- 令 $x = a \tan t$，则 $dx = a \sec^2 t dt$

- 原式$= \int \frac{a \sec^2 t dt}{a^2 + a^2 \tan^2 t} = \int \frac{a \sec^2 t dt}{a^2 \sec^2 t} = \frac{1}{a} \int dt = \frac{t}{a} + C = \frac{1}{a} \arctan \frac{x}{a} + C$

2. 第二类换元积分法

2.1 基本原理

第二类换元积分法是引入新的变量来简化积分计算。

设 $x = \phi(t)$，其中 $\phi(t)$ 单调、可导，且 $\phi'(t) \neq 0$，则：

$$\int f(x) dx = \int f(\phi(t)) \phi'(t) dt$$

2.2 三角换元法

根据被积函数中根号的不同形式，选择不同的三角换元：

  • $\sqrt{a^2 - x^2}$：令 $x = a \sin t$ 或 $x = a \cos t$
  • $\sqrt{a^2 + x^2}$：令 $x = a \tan t$
  • $\sqrt{x^2 - a^2}$：令 $x = a \sec t$

2.3 典型例题

  • $\int \sqrt{a^2 - x^2} dx$

- 令 $x = a \sin t$，则 $dx = a \cos t dt$，$\sqrt{a^2 - x^2} = a \cos t$

- 原式$= \int a \cos t \cdot a \cos t dt = a^2 \int \cos^2 t dt = a^2 \int \frac{1 + \cos 2t}{2} dt$

- $= \frac{a^2}{2} (t + \frac{\sin 2t}{2}) + C = \frac{a^2}{2} (t + \sin t \cos t) + C$

- 代回 $t = \arcsin \frac{x}{a}$，$\sin t = \frac{x}{a}$，$\cos t = \frac{\sqrt{a^2 - x^2}}{a}$

- $= \frac{a^2}{2} \arcsin \frac{x}{a} + \frac{x}{2} \sqrt{a^2 - x^2} + C$

  • $\int \frac{dx}{\sqrt{x^2 + a^2}}$

- 令 $x = a \tan t$，则 $dx = a \sec^2 t dt$，$\sqrt{x^2 + a^2} = a \sec t$

- 原式$= \int \frac{a \sec^2 t dt}{a \sec t} = \int \sec t dt = \ln|\sec t + \tan t| + C$

- 代回得：$= \ln\left|x + \sqrt{x^2 + a^2}\right| + C$

  • $\int \frac{dx}{\sqrt{x^2 - a^2}}$

- 令 $x = a \sec t$，则 $dx = a \sec t \tan t dt$，$\sqrt{x^2 - a^2} = a \tan t$

- 原式$= \int \frac{a \sec t \tan t dt}{a \tan t} = \int \sec t dt = \ln|\sec t + \tan t| + C$

- 代回得：$= \ln\left|x + \sqrt{x^2 - a^2}\right| + C$

3. 换元积分法的综合应用

3.1 有理函数的不定积分

对于有理函数 $\frac{P(x)}{Q(x)}$，其中分子的次数低于分母：

  • 部分分式分解
  • 逐项积分

例：$\int \frac{dx}{x^2 - a^2}$

- $\frac{1}{x^2 - a^2} = \frac{1}{2a} (\frac{1}{x - a} - \frac{1}{x + a})$

- 原式$= \frac{1}{2a} \int (\frac{1}{x - a} - \frac{1}{x + a}) dx = \frac{1}{2a} \ln\left|\frac{x - a}{x + a}\right| + C$

3.2 三角函数的不定积分

  • $\int \sin^n x dx$：利用递推公式或降幂公式
  • $\int \cos^n x dx$：类似方法
  • $\int \tan^n x dx$：利用 $\tan^2 x = \sec^2 x - 1$

例：$\int \sin^3 x dx$

- 原式$= \int \sin^2 x \sin x dx = \int (1 - \cos^2 x) \sin x dx$

- 令 $u = \cos x$，$du = -\sin x dx$

- 原式$= -\int (1 - u^2) du = -u + \frac{u^3}{3} + C = -\cos x + \frac{\cos^3 x}{3} + C$

3.3 指数函数与对数函数的不定积分

  • $\int a^x dx = \frac{a^x}{\ln a} + C$
  • $\int x^n e^x dx$：需要使用分部积分法

学习建议

  • 熟记基本积分公式和常见的凑微分形式
  • 多做练习，培养对积分形式的敏感度
  • 注意三角换元法的三种基本类型及其适用条件
  • 灵活运用换元法和分部积分法解决复杂积分
