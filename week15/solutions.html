第15周：练习答案

多元函数概念

选择题

  • B. $x^2 + y^2 < 4$

解析：需 $4 - x^2 - y^2 > 0$，即 $x^2 + y^2 < 4$。

  • A. $x + y > 0$

解析：对数函数定义域要求真数大于零。

填空题

  • $5$

解析：$f(1, 2) = 1^2 + 2^2 = 5$。

  • 空间中的一张曲面

极限与连续

选择题

  • C. 不存在

解析：沿不同路径 $y = kx$ 趋近时，$\frac{xy}{x^2 + y^2} = \frac{k}{1 + k^2}$，值随 $k$ 变化而不同。

  • B. 不连续

解析：极限 $\lim_{(x,y) \to (0,0)} \frac{xy}{x^2 + y^2}$ 不存在（与路径有关），与函数值 $0$ 不相等。

填空题

  • 连续
  • 沿所有路径的极限都存在且相等

解答题

  • 不存在

解析：沿 $y = x$ 趋近得 $2$，沿 $y = 2x$ 趋近得 $\frac{3}{2}$，不相等。

  • 不连续

解析：极限与路径有关。

偏导数

选择题

  • A. $3x^2 y^2$

解析：$f_x = \frac{\partial (x^3 y^2)}{\partial x} = 3x^2 y^2$。

  • B. $y e^{xy}$

解析：$\frac{\partial e^{xy}}{\partial x} = e^{xy} \cdot y$。

填空题

  • $\frac{2x}{x^2 + y^2}$；$\frac{2y}{x^2 + y^2}$
  • $2 \sin y$

解析：$f_{xx} = \frac{\partial^2 (x^2 \sin y)}{\partial x^2} = 2 \sin y$。

解答题

  • $\frac{\partial z}{\partial x} = 2xy + \frac{1}{y} e^{x/y}$，$\frac{\partial z}{\partial y} = x^2 - \frac{x}{y^2} e^{x/y}$
  • $f_{xx} = \frac{2xy}{(x^2 + y^2)^2}$，$f_{yy} = \frac{-2xy}{(x^2 + y^2)^2}$，$f_{xy} = \frac{y^2 - x^2}{(x^2 + y^2)^2}$，$f_{yx} = \frac{y^2 - x^2}{(x^2 + y^2)^2}$

全微分

选择题

  • A. $2x dx + 2y dy$

解析：$dz = \frac{\partial z}{\partial x} dx + \frac{\partial z}{\partial y} dy = 2x dx + 2y dy$。

  • A. $e dx + e dy$

解析：$dz = ye^{xy} dx + xe^{xy} dy$，在 $(1,1)$ 处为 $e dx + e dy$。

填空题

  • 偏导数存在且连续（或函数可微）
  • 必定存在

解答题

  • $dz = \cos(x + y) dx + \cos(x + y) dy = \cos(x + y)(dx + dy)$
  • $du = yz dx + xz dy + xy dz$
  • $dz = \frac{x}{\sqrt{x^2 + y^2}} dx + \frac{y}{\sqrt{x^2 + y^2}} dy$，在 $(3,4)$ 处：$dz = \frac{3}{5} \cdot 0.1 + \frac{4}{5} \cdot 0.2 = 0.14 + 0.16 = 0.3$

方向导数与梯度

选择题

  • A. $2\sqrt{2}$

解析：$\nabla f = (2x, 2y) = (2, 2)$，沿梯度方向的大小为 $|\nabla f| = 2\sqrt{2}$。

填空题

  • $(\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y})$
  • 梯度的大小

解答题

  • $\vec{l}$ 的单位向量为 $(\frac{1}{\sqrt{2}}, \frac{1}{\sqrt{2}})$，$\nabla f = (2x + y, x + 2y) = (3, 3)$，$\frac{\partial f}{\partial \vec{l}} = 3 \cdot \frac{1}{\sqrt{2}} + 3 \cdot \frac{1}{\sqrt{2}} = 3\sqrt{2}$
  • $\nabla f = (\frac{x}{x^2 + y^2}, \frac{y}{x^2 + y^2})$
