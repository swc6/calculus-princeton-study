A. $x \sin x + \cos x + C$

B. $x \sin x - \cos x + C$

C. $-x \sin x + \cos x + C$

D. $-x \sin x - \cos x + C$

A. $x \ln x + C$

B. $x \ln x - x + C$

C. $\frac{(\ln x)^2}{2} + C$

D. $\frac{1}{x} + C$

  • $\int x^2 e^x dx = $

A. $x^2 e^x + C$

B. $(x^2 - 2x + 2)e^x + C$

C. $(x^2 + 2x + 2)e^x + C$

D. $(x^2 - 2x)e^x + C$

部分分式分解

选择题

  • $\frac{1}{(x - 1)(x - 2)} = $

A. $\frac{1}{x - 1} + \frac{1}{x - 2}$

B. $\frac{1}{x - 1} - \frac{1}{x - 2}$

C. $\frac{1}{x - 2} - \frac{1}{x - 1}$

D. $\frac{1}{(x - 1)(x - 2)}$

  • $\frac{x}{(x - 1)^2} = $

A. $\frac{1}{x - 1} + \frac{1}{(x - 1)^2}$

B. $\frac{1}{x - 1} - \frac{1}{(x - 1)^2}$

C. $\frac{1}{(x - 1)^2}$

D. $\frac{x}{(x - 1)^2}$

  • $\frac{1}{x^2 + x - 2} = $

A. $\frac{1}{3(x - 1)} - \frac{1}{3(x + 2)}$

B. $\frac{1}{3(x + 1)} - \frac{1}{3(x - 2)}$

C. $\frac{1}{x - 1} + \frac{1}{x + 2}$

D. $\frac{1}{x - 1} - \frac{1}{x + 2}$

填空题

  • $\frac{1}{x^2 - 4} = $ __________
  • $\frac{x + 1}{x(x - 1)} = $ __________
  • $\frac{2x + 3}{(x - 1)(x^2 + 1)} = $ __________

  • 求$\int \frac{1}{x^2 - 5x + 6} dx$。

  • 求$\int \frac{1}{x(x - 1)^2} dx$。

  • 求$\int \frac{1}{x^3 + x} dx$。
  • 求$\int \frac{x}{x^2 + 2x + 2} dx$。
  • 求$\int \frac{x^2}{(x - 1)^3} dx$。
  • 求$\int \frac{1}{x^4 - 1} dx$。
