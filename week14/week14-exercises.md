# 第14周：练习题目

## 函数值的近似计算

### 选择题
1. 利用 $e^x$ 的麦克劳林级数计算 $e^{0.2}$，取前三项（$1 + x + \frac{x^2}{2}$）的近似值为（ ）
   A. $1.2$
   B. $1.22$
   C. $1.202$
   D. $1.02$

2. 用 $\ln(1+x)$ 的展开式计算 $\ln 1.1$，取 $x - \frac{x^2}{2}$ 两项，误差不超过（ ）
   A. $\frac{0.1^3}{3}$
   B. $\frac{0.1^2}{2}$
   C. $\frac{0.1^3}{3!}$
   D. $0.001$

3. 计算 $\cos 5^{\circ}$ 的近似值，正确的做法是（ ）
   A. 直接代入 $\cos x \approx 1 - \frac{x^2}{2}$，$x = 5$
   B. 先化为弧度 $x = \frac{\pi}{36}$，再代入级数
   C. 先化为弧度 $x = \frac{\pi}{180}$，再代入级数
   D. 不能用泰勒级数计算

### 填空题
1. 用 $(1+x)^{1/2}$ 的展开式计算 $\sqrt{1.04}$，取到 $x$ 一次项的近似值为 __________

2. $e^{0.1}$ 用级数 $1 + x + \frac{x^2}{2!} + \frac{x^3}{3!}$ 近似的值为 __________（保留 4 位小数）

3. 用 $\arctan x = x - \frac{x^3}{3} + \cdots$ 计算 $\arctan 0.2$，取两项的近似值为 __________

### 解答题
1. 利用 $\ln(1+x)$ 的麦克劳林级数计算 $\ln 1.1$ 的近似值，使误差不超过 $10^{-4}$，写明所取项数与误差估计依据。

2. 计算 $\sin 3^{\circ}$ 的近似值（取到 $x^3$ 项），并用交错级数余项估计误差。

3. 利用 $(1+x)^{-1/2}$ 的展开式计算 $\frac{1}{\sqrt{1.05}}$ 的近似值（取到 $x^2$ 项）。

4. 用级数方法计算 $\sqrt[3]{9}$ 的近似值（提示：$\sqrt[3]{9} = 2\left(1 + \frac{1}{8}\right)^{1/3}$，取到 $x^2$ 项）。

5. 计算 $\cos 0.3$ 的近似值，使误差小于 $10^{-5}$，写明所取项数与理由。

6. 用 $e^x$ 的展开式计算 $e^{-0.5}$ 的近似值（取前四项），并用交错级数余项估计误差。

## 定积分的近似计算

### 选择题
1. $\int_0^{0.1} e^{-x^2} dx$ 用级数 $x - \frac{x^3}{3} + \cdots$ 计算时，第一项 $0.1$ 的误差约为（ ）
   A. $3.3 \times 10^{-4}$
   B. $3.3 \times 10^{-5}$
   C. $10^{-2}$
   D. $10^{-6}$

2. 积分 $\int_0^1 \frac{\sin x}{x} dx$ 的特点是（ ）
   A. 等于 $\sin 1$
   B. 原函数不是初等函数，需用级数或其他数值方法计算
   C. 等于 $0$
   D. 发散

3. 计算 $\int_0^{0.5} \frac{dx}{1+x^4}$，正确的做法是（ ）
   A. 先积分再代值
   B. 将 $\frac{1}{1+x^4}$ 展开为 $\sum (-1)^n x^{4n}$ 后逐项积分
   C. 无法计算
   D. 用 $\int \frac{dx}{1+x}$ 的公式

### 填空题
1. $\int_0^{0.2} e^{-x^2} dx \approx$ __________（用级数前两项 $x - \frac{x^3}{3}$ 计算）

2. 由 $\frac{1}{1+x^4} = \sum_{n=0}^{\infty} (-1)^n x^{4n}$，$\int_0^{0.5} \frac{dx}{1+x^4}$ 的级数表达式第一项与第二项之和为 __________

3. $\int_0^{1} \frac{\sin x}{x} dx$ 的级数展开中被积函数为 $\sum_{n=0}^{\infty} \frac{(-1)^n x^{2n}}{(2n+1)!}$，则积分为 $\sum_{n=0}^{\infty} \frac{(-1)^n}{(2n+1)!\,\underline{\ \ \ \ }}$（补全分母）

### 解答题
1. 利用 $e^{-x^2}$ 的麦克劳林级数计算 $\int_0^{0.5} e^{-x^2} dx$，使误差不超过 $10^{-4}$，写明所取项数与误差依据。

2. 利用 $\frac{\sin x}{x}$ 的级数计算 $\int_0^1 \frac{\sin x}{x} dx$ 的近似值（取前三项），并估计误差。

3. 将 $\int_0^{0.3} \cos(x^2) dx$ 用级数表示并计算近似值（取到 $x^8$ 对应的积分项）。

4. 计算 $\int_0^{0.4} \ln(1+x^2) dx$ 的近似值（取级数前两项）。

5. 利用级数说明 $\int_0^{1} e^{-x^2} dx$ 与 $0.75$ 的大小关系（给出估计即可）。

6. 用级数方法计算 $\int_0^{0.5} \frac{x\,dx}{1+x^3}$ 的近似值（取前两项）。

## 幂级数法解微分方程

### 选择题
1. 设 $y = \sum_{n=0}^{\infty} a_n x^n$ 是 $y'' = y$ 的解，则系数满足（ ）
   A. $a_{n+2} = \frac{a_n}{(n+1)(n+2)}$
   B. $a_{n+1} = a_n$
   C. $a_{n+2} = (n+1)(n+2)a_n$
   D. $a_{n+2} = \frac{a_n}{n+2}$

2. 方程 $y'' + xy = 0$ 的解（ ）
   A. 是初等函数
   B. 一般不是初等函数，需用幂级数表示
   C. 只有零解
   D. 是多项式

3. 用幂级数法解 $y' = y$，$y(0) = 1$，所得解为（ ）
   A. $\cos x$
   B. $e^x$
   C. $\frac{1}{1-x}$
   D. $\ln(1+x)$

### 填空题
1. 设 $y = \sum a_n x^n$ 解 $y'' - 2y = 0$，$y(0)=1$，$y'(0)=0$，则 $a_2 =$ __________，$a_4 =$ __________

2. 用幂级数法解 $y' = xy$，$y(0) = 1$，则解的前三项为 $y \approx$ __________

3. 设 $y = \sum a_n x^n$ 代入 $y'' + y = 0$，比较 $x^n$ 系数得递推关系 $a_{n+2} =$ __________

### 解答题
1. 用幂级数法求解 $y'' - y = 0$，$y(0) = 0$，$y'(0) = 1$，并将结果与初等函数对照。

2. 用幂级数法求 $y' = y$，$y(0) = 1$ 的解，验证其为 $e^x$。

3. 用幂级数法求 $y'' + x^2 y = 0$ 的满足 $y(0)=1$，$y'(0)=0$ 的级数解（写出含 $a_0$ 的递推式及前四个非零项）。

4. 用幂级数法求 $y'' + y = 0$，$y(0)=0$，$y'(0)=1$ 的级数解，并与 $\sin x$ 对照。

5. 用幂级数法求解 $y' - 2xy = 0$，$y(0) = 1$（提示：递推式中奇偶项分离）。

6. 设 $y = \sum a_n x^n$ 是 $y'' + xy' + y = 0$ 的解，试推导系数递推关系。

## 综合应用题

1. 用泰勒级数计算 $\sin 0.2$ 的近似值，使误差小于 $10^{-6}$，写明所取项数与误差估计。

2. 计算 $\int_0^{0.2} \frac{\sin x}{x} dx$ 的近似值，使误差小于 $10^{-7}$。

3. 用幂级数法解 $y'' - x y' - y = 0$，$y(0) = 1$，$y'(0) = 0$，并尝试认出该解的封闭形式（提示：$e^{x^2/2}$ 的导数关系）。

4. 证明：当 $|x|$ 很小时，用 $\frac{x}{1+x}$ 近似 $\ln(1+x)$ 的误差约为 $\frac{x^2}{2}$（即两式之差的首项为 $\frac{x^2}{2}$）。

5. 利用欧拉公式 $e^{ix} = \cos x + i\sin x$，将 $\cos x$ 写成复指数形式，并用它说明 $\cos x$ 的麦克劳林级数只含偶数次幂。

6. 用级数比较：当 $x \to 0^+$ 时，$\int_0^x \frac{\sin t}{t} dt$ 与 $x$ 之差的首项是多少？

7. 单摆周期公式为 $T = 4\sqrt{\frac{L}{g}}\,K\left(\sin\frac{\theta_0}{2}\right)$ 的形式，其中幅角修正可用 $\left(1 + \frac{1}{2}\sin^2\frac{\theta_0}{2} + \cdots\right)$ 表示。取 $\theta_0 = 30^{\circ}$，用第一修正项估算 $T$ 相对小角近似 $2\pi\sqrt{\frac{L}{g}}$ 增加的百分比。

8. 设某量 $A(x) = A_0 e^{kx}$，用麦克劳林级数写出 $A(x)$ 的二阶近似式，并据此估计 $k = 0.03$、$x = 1$ 时二阶近似与精确值的相对误差（取 $e^{0.03}$ 精确到 $10^{-6}$ 比较即可）。
