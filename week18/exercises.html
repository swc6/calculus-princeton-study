第18周：综合复习练习

极限与连续

解答题

  • 求 $\lim_{x \to 0} \frac{\sin x - x \cos x}{x^3}$。
  • 求 $\lim_{x \to \infty} (1 + \frac{2}{x})^{x}$。
  • 求 $\lim_{x \to 0} \frac{e^x - e^{\sin x}}{x - \sin x}$。

导数与微分

解答题

  • 求 $y = \arctan \sqrt{x}$ 的导数。
  • 求由方程 $e^y + xy = e$ 确定的隐函数 $y = f(x)$ 的导数 $\frac{dy}{dx}$。
  • 求 $y = x^{\sin x}$ 的导数。
  • 求 $f(x) = x^3 - 3x^2 + 2$ 的增减区间和极值。

积分

解答题

  • 计算 $\int \frac{x}{\sqrt{1 + x^2}} dx$。
  • 计算 $\int_0^1 x e^x dx$。
  • 计算 $\int_0^1 \frac{dx}{1 + \sqrt{x}}$。
  • 求由 $y = x^2$ 和 $y = \sqrt{x}$ 围成的图形面积。

级数

解答题

  • 判断 $\sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n}$ 的敛散性。
  • 求 $\sum_{n=0}^{\infty} \frac{x^n}{n!}$ 的收敛半径。
  • 将 $f(x) = \ln(1 + x)$ 展开成麦克劳林级数。
  • 求 $\sum_{n=0}^{\infty} \frac{x^{2n+1}}{2n+1}$ 的和函数。

多元函数

解答题

  • 求 $z = x^2 + y^2$ 在点 $(1, 2)$ 处的全微分。
  • 求 $z = e^{xy}$ 的二阶偏导数。
  • 求 $f(x, y) = x^2 + xy + y^2$ 在约束条件 $x + y = 1$ 下的极值。
  • 计算 $\iint_D xy d\sigma$，其中 $D: 0 \leq x \leq 1$，$0 \leq y \leq 1$。

综合应用

解答题

  • 一质量为 $m$ 的物体从距离地面 $h$ 处自由下落，求重力所做的功。
  • 求半径为 $R$ 的球的表面积。
  • 利用泰勒级数计算 $\int_0^1 \frac{\sin x}{x} dx$ 的近似值（取前3项）。
  • 求曲面 $z = x^2 + y^2$ 在点 $(1, 1, 2)$ 处的切平面方程。
