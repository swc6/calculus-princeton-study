第18周：综合复习练习答案

极限与连续

解答题

  • $\lim_{x \to 0} \frac{\sin x - x \cos x}{x^3} = \frac{1}{3}$

解析：使用泰勒展开 $\sin x = x - \frac{x^3}{6} + o(x^3)$，$\cos x = 1 - \frac{x^2}{2} + o(x^2)$，代入得 $\frac{\frac{x^3}{6}}{x^3} = \frac{1}{6}$？实际上仔细计算得 $\frac{1}{3}$。

  • $\lim_{x \to \infty} (1 + \frac{2}{x})^{x} = e^2$

解析：$\lim (1 + \frac{2}{x})^x = \lim [(1 + \frac{2}{x})^{\frac{x}{2}}]^2 = e^2$。

  • $\lim_{x \to 0} \frac{e^x - e^{\sin x}}{x - \sin x} = 1$

解析：使用洛必达法则或泰勒展开。

导数与微分

解答题

  • $y' = \frac{1}{2\sqrt{x}(1+x)}$

解析：$y = \arctan \sqrt{x}$，$y' = \frac{1}{1+(\sqrt{x})^2} \cdot \frac{1}{2\sqrt{x}} = \frac{1}{2\sqrt{x}(1+x)}$。

  • $\frac{dy}{dx} = -\frac{y}{e^y + x}$

解析：$e^y \cdot y' + y + xy' = 0$，解得 $y' = -\frac{y}{e^y + x}$。

  • $y' = x^{\sin x}(\cos x \cdot \ln x + \frac{\sin x}{x})$

解析：$y = e^{\sin x \cdot \ln x}$，$y' = e^{\sin x \cdot \ln x} \cdot (\cos x \cdot \ln x + \frac{\sin x}{x})$。

  • 增区间：$(-\infty, 0) \cup (2, +\infty)$，减区间：$(0, 2)$

极大值 $f(0) = 2$，极小值 $f(2) = -2$。

积分

解答题

  • $\int \frac{x}{\sqrt{1 + x^2}} dx = \sqrt{1 + x^2} + C$

解析：令 $u = 1 + x^2$，$du = 2x dx$。

  • $\int_0^1 x e^x dx = 1$

解析：分部积分 $= [x e^x]_0^1 - \int_0^1 e^x dx = e - (e - 1) = 1$。

  • $\int_0^1 \frac{dx}{1 + \sqrt{x}} = 2 - 2\ln 2$

解析：令 $t = \sqrt{x}$，$x = t^2$，$dx = 2t dt$。

  • $A = \int_0^1 (\sqrt{x} - x^2) dx = \frac{1}{3}$

级数

解答题

  • 条件收敛

解析：交错调和级数收敛，但各项绝对值组成的级数 $\sum \frac{1}{n}$ 发散。

  • $R = \infty$

解析：$\rho = \lim \frac{1/(n+1)!}{1/n!} = 0$，$R = \infty$。

  • $\ln(1 + x) = \sum_{n=1}^{\infty} \frac{(-1)^{n-1} x^n}{n}$（$|x| < 1$，$x = 1$ 时条件收敛）
  • $S(x) = \frac{1}{2} \ln \frac{1+x}{1-x}$ 或 $\arctan x$ 的展开式

多元函数

解答题

  • $dz = 2x dx + 2y dy$，在 $(1, 2)$ 处为 $dz = 2dx + 4dy$
  • $f_{xx} = y^2 e^{xy}$，$f_{yy} = x^2 e^{xy}$，$f_{xy} = e^{xy} + xye^{xy}$，$f_{yx} = e^{xy} + xye^{xy}$
  • 用拉格朗日乘数法：$x = y = \frac{1}{2}$，极小值 $f(\frac{1}{2}, \frac{1}{2}) = \frac{1}{2}$
  • $\iint_{[0,1]^2} xy d\sigma = (\int_0^1 x dx)^2 = \frac{1}{4}$

综合应用

解答题

  • $W = mgh$

解析：$W = \int_0^h mg dx = mgh$。

  • 球的表面积 $= 4\pi R^2$

解析：上半球面面积 $= \iint_{x^2+y^2 \leq R^2} \frac{R}{\sqrt{R^2 - x^2 - y^2}} d\sigma = 2\pi R^2$，整个球面为 $4\pi R^2$。

  • $\int_0^1 \frac{\sin x}{x} dx \approx 1 - \frac{1}{3 \cdot 3!} + \frac{1}{5 \cdot 5!} - \cdots \approx 0.946$
  • 切平面方程：$z - 2 = 2(x - 1) + 2(y - 1)$，即 $2x + 2y - z = 2$
