第11周：积分的应用

学习目标

  • 掌握用定积分求平面图形面积的方法
  • 学会用定积分计算旋转体体积

  • 理解定积分在物理中的应用
  • 能够综合运用积分解决实际问题

学习内容

1. 平面图形的面积

1.1 由曲线围成的面积

由曲线 $y = f(x)$（$f(x) \geq 0$）、$x$ 轴、直线 $x = a$ 和 $x = b$ 围成的面积：

$$A = \int_a^b f(x) dx$$

一般情况（$f(x)$ 可正可负）：

$$A = \int_a^b |f(x)| dx$$

1.2 两曲线之间的面积

由曲线 $y = f(x)$ 和 $y = g(x)$（$f(x) \geq g(x)$）以及直线 $x = a$ 和 $x = b$ 围成的面积：

$$A = \int_a^b [f(x) - g(x)] dx$$

1.3 例题

  • 求由抛物线 $y = x^2$ 和直线 $y = x$ 围成的图形面积。

- 解方程组得交点：$(0, 0)$ 和 $(1, 1)$

- $A = \int_0^1 (x - x^2) dx = [\frac{x^2}{2} - \frac{x^3}{3}]_0^1 = \frac{1}{2} - \frac{1}{3} = \frac{1}{6}$

  • 求由 $y = \sin x$、$x$ 轴、$x = 0$ 和 $x = \pi$ 围成的面积。

- $A = \int_0^\pi |\sin x| dx = \int_0^\pi \sin x dx = [-\cos x]_0^\pi = 2$

2. 旋转体体积

2.1 旋转体的概念

旋转体是由平面图形绕某一条固定直线（旋转轴）旋转而成的立体。

2.2 体积公式（切片法）

由曲线 $y = f(x)$、$x$ 轴、直线 $x = a$ 和 $x = b$ 围成的图形绕 $x$ 轴旋转一周所得旋转体体积：

$$V = \int_a^b \pi [f(x)]^2 dx$$

绕 $y$ 轴旋转所得旋转体体积：

$$V = \int_a^b 2\pi x |f(x)| dx$$

2.3 例题

  • 求由 $y = x^2$、$x$ 轴、$x = 0$ 和 $x = 1$ 围成的图形绕 $x$ 轴旋转一周所得旋转体体积。

- $V = \int_0^1 \pi (x^2)^2 dx = \pi \int_0^1 x^4 dx = \pi [\frac{x^5}{5}]_0^1 = \frac{\pi}{5}$

  • 求由 $y = \sqrt{x}$、$x$ 轴、$x = 1$ 和 $x = 4$ 围成的图形绕 $y$ 轴旋转所得旋转体体积。

- $V = \int_1^4 2\pi x \sqrt{x} dx = 2\pi \int_1^4 x^{\frac{3}{2}} dx = 2\pi [\frac{2}{5} x^{\frac{5}{2}}]_1^4 = \frac{4\pi}{5} (32 - 1) = \frac{124\pi}{5}$

2.4 圆柱壳法

当旋转轴是 $y$ 轴，而图形由 $x = g(y)$、$y$ 轴等围成时，用圆柱壳法更方便：

$$V = \int_c^d 2\pi y |g(y)| dy$$

3. 平面曲线的弧长

3.1 弧长公式

对于参数方程 $x = \phi(t)$，$y = \psi(t)$（$t \in [\alpha, \beta]$），弧长：

$$s = \int_\alpha^\beta \sqrt{[\phi'(t)]^2 + [\psi'(t)]^2} dt$$

对于直角坐标系 $y = f(x)$（$x \in [a, b]$），弧长：

$$s = \int_a^b \sqrt{1 + [f'(x)]^2} dx$$

对于极坐标系 $r = f(\theta)$（$\theta \in [\alpha, \beta]$），弧长：

$$s = \int_\alpha^\beta \sqrt{[f(\theta)]^2 + [f'(\theta)]^2} d\theta$$

3.2 例题

  • 求曲线 $y = \frac{2}{3}x^{3/2}$ 从 $x = 0$ 到 $x = 3$ 的弧长。

- $y' = x^{1/2}$，$1 + (y')^2 = 1 + x$

- $s = \int_0^3 \sqrt{1 + x} dx = [\frac{2}{3}(1 + x)^{3/2}]_0^3 = \frac{2}{3}(8 - 1) = \frac{14}{3}$

  • 求圆 $x^2 + y^2 = r^2$ 的周长。

- 上半圆：$y = \sqrt{r^2 - x^2}$，$y' = -\frac{x}{\sqrt{r^2 - x^2}}$

- $1 + (y')^2 = 1 + \frac{x^2}{r^2 - x^2} = \frac{r^2}{r^2 - x^2}$

- $s = 4\int_0^r \frac{r}{\sqrt{r^2 - x^2}} dx = 4r [\arcsin \frac{x}{r}]_0^r = 4r \cdot \frac{\pi}{2} = 2\pi r$

4. 定积分在物理中的应用

4.1 功

变力做功：物体在力 $F(x)$ 的作用下从 $x = a$ 移动到 $x = b$，力所做的功：

$$W = \int_a^b F(x) dx$$

例：弹簧的弹力 $F = kx$，将弹簧从原长拉伸 $d$ 所做的功：

$$W = \int_0^d kx dx = \frac{1}{2}kd^2$$

4.2 液体压力

平板垂直放入液体中，距液面深度为 $h$ 处的压强为 $p = \rho g h$，其中 $\rho$ 为液体密度，$g$ 为重力加速度。

面积为 $A$ 的平板所受压力：

$$P = \int_A p dA$$

4.3 引力

万有引力定律：$F = G\frac{m_1 m_2}{r^2}$

5. 积分的近似计算

5.1 梯形法

将区间 $[a, b]$ 分成 $n$ 个等份，用梯形面积近似代替曲边梯形面积：

$$\int_a^b f(x) dx \approx \frac{b-a}{2n} [f(x_0) + 2\sum_{i=1}^{n-1} f(x_i) + f(x_n)]$$

5.2 辛普森法

用抛物线逼近，每两个小区间合成为一个计算单元：

$$\int_a^b f(x) dx \approx \frac{b-a}{6n} [f(x_0) + 4\sum_{i=1,3,5,\ldots}^{2n-1} f(x_i) + 2\sum_{i=2,4,6,\ldots}^{2n-2} f(x_i) + f(x_{2n})]$$
