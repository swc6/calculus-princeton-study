第11周：练习答案

平面图形面积

选择题

  • B. $\frac{4}{3}$

解析：交点为 $(0, 0)$ 和 $(2, 4)$，面积 $A = \int_0^2 (2x - x^2) dx = [x^2 - \frac{x^3}{3}]_0^2 = 4 - \frac{8}{3} = \frac{4}{3}$。

  • A. $e - 1$

解析：$A = \int_0^1 e^x dx = [e^x]_0^1 = e - 1$。

填空题

  • $1$

解析：$A = \int_0^{\pi/2} \cos x dx = [\sin x]_0^{\pi/2} = 1$。

  • $1$

解析：$A = \int_1^e \ln x dx = [x \ln x - x]_1^e = (e - e) - (-1) = 1$。

解答题

  • $A = \int_0^4 (4x - x^2) dx = [2x^2 - \frac{x^3}{3}]_0^4 = 32 - \frac{64}{3} = \frac{32}{3}$

解析：由 $4x - x^2 = 0$ 得交点 $x = 0$ 和 $x = 4$，面积即为两交点之间函数与 $x$ 轴围成的面积。

  • 在 $x \in [0, \frac{\pi}{4}]$，$\cos x > \sin x$；在 $x \in [\frac{\pi}{4}, \pi]$，$\sin x > \cos x$。

面积 $A = \int_0^{\pi/4} (\cos x - \sin x) dx + \int_{\pi/4}^\pi (\sin x - \cos x) dx$

$= [\sin x + \cos x]_0^{\pi/4} + [-\cos x - \sin x]_{\pi/4}^\pi$

$= (\frac{\sqrt{2}}{2} + \frac{\sqrt{2}}{2} - 1) + (1 + 0 + \frac{\sqrt{2}}{2} + \frac{\sqrt{2}}{2})$

$= 2\sqrt{2}$

  • 交点为 $(0, 0)$ 和 $(1, 1)$，在 $x \in [-1, 0]$，$x > x^3$；在 $x \in [0, 1]$，$x^3 > x$。

$A = \int_{-1}^0 (x - x^3) dx + \int_0^1 (x^3 - x) dx$

$= [\frac{x^2}{2} - \frac{x^4}{4}]_{-1}^0 + [\frac{x^4}{4} - \frac{x^2}{2}]_0^1 = \frac{1}{4} + (-\frac{1}{4}) = \frac{1}{2}$

旋转体体积

选择题

  • C. $\frac{\pi}{5}$

解析：$V = \int_0^1 \pi (x^2)^2 dx = \pi \int_0^1 x^4 dx = \pi [\frac{x^5}{5}]_0^1 = \frac{\pi}{5}$。

  • A. $\frac{124\pi}{5}$

解析：$V = \int_1^4 2\pi x \sqrt{x} dx = 2\pi \int_1^4 x^{3/2} dx = 2\pi [\frac{2}{5} x^{5/2}]_1^4 = \frac{4\pi}{5} (32 - 1) = \frac{124\pi}{5}$。

填空题

  • $\frac{\pi}{2}(e^2 - 1)$

解析：$V = \int_0^1 \pi (e^x)^2 dx = \pi \int_0^1 e^{2x} dx = \pi [\frac{e^{2x}}{2}]_0^1 = \frac{\pi}{2}(e^2 - 1)$。

  • $\frac{4}{3}\pi r^3$

解析：球看成由上半圆 $y = \sqrt{r^2 - x^2}$ 绕 $x$ 轴旋转而成，$V = \int_{-r}^r \pi (r^2 - x^2) dx = \frac{4}{3}\pi r^3$。

解答题

  • 交点为 $(0, 0)$ 和 $(1, 1)$。

$V = \int_0^1 \pi [(\sqrt{x})^2 - (x)^2] dx = \pi \int_0^1 (x - x^2) dx = \pi [\frac{x^2}{2} - \frac{x^3}{3}]_0^1 = \pi(\frac{1}{2} - \frac{1}{3}) = \frac{\pi}{6}$

  • 交点为 $(0, 0)$ 和 $(1, 1)$。

$V = \int_0^1 2\pi y (y^2 - y) dy = 2\pi \int_0^1 (y^3 - y^2) dy = 2\pi [\frac{y^4}{4} - \frac{y^3}{3}]_0^1 = 2\pi(\frac{1}{4} - \frac{1}{3}) = -\frac{\pi}{6}$，取绝对值得 $\frac{\pi}{6}$。

  • 上半球：$y = \sqrt{r^2 - x^2}$，绕 $x$ 轴旋转

$V = \int_{-r}^r \pi (r^2 - x^2) dx = \pi [r^2 x - \frac{x^3}{3}]_{-r}^r = \pi(2r^3 - \frac{2r^3}{3}) = \frac{4\pi r^3}{3}$

平面曲线弧长

选择题

  • B. $\frac{14}{3}$

解析：$y' = x^{1/2}$，$1 + (y')^2 = 1 + x$，$s = \int_0^3 \sqrt{1 + x} dx = [\frac{2}{3}(1 + x)^{3/2}]_0^3 = \frac{14}{3}$。

  • A. $\ln(\sqrt{2} + 1)$

解析：$y' = \tan x \sec x$，$1 + (y')^2 = \sec^2 x$，$s = \int_0^{\pi/4} \sec x dx = [\ln|\sec x + \tan x|]_0^{\pi/4} = \ln(\sqrt{2} + 1)$。

填空题

  • $\frac{8}{3}$

解析：$y' = \frac{3}{2}x^{1/2}$，$1 + (y')^2 = 1 + \frac{9x}{4}$，$s = \int_0^4 \sqrt{1 + \frac{9x}{4}} dx = \frac{8}{27}[(1 + \frac{9x}{4})^{3/2}]_0^4 = \frac{8}{3}$。

  • $8a$

解析：$x' = a(1 - \cos t)$，$y' = a\sin t$，$s = \int_0^{2\pi} \sqrt{a^2(1 - \cos t)^2 + a^2\sin^2 t} dt = \int_0^{2\pi} a\sqrt{2 - 2\cos t} dt = 2a \int_0^{2\pi} \sin\frac{t}{2} dt = 8a$。

解答题

  • $y' = x^3 - \frac{1}{x^3}$，$1 + (y')^2 = (x^3 + \frac{1}{x^3})^2$

$s = \int_1^2 \sqrt{(x^3 + \frac{1}{x^3})^2} dx = \int_1^2 (x^3 + \frac{1}{x^3}) dx = [\frac{x^4}{4} - \frac{1}{2x^2}]_1^2 = \frac{33}{8}$

  • $r' = e^\theta$，$s = \int_0^\pi \sqrt{e^{2\theta} + e^{2\theta}} d\theta = \int_0^\pi e^\theta \sqrt{2} d\theta = \sqrt{2}(e^\pi - 1)$

定积分物理应用

选择题

  • B. $\frac{1}{2}kd^2$

解析：$W = \int_0^d kx dx = \frac{1}{2}kd^2$。

  • A. $mgh$

解析：$W = \int_0^h mg dx = mgh$。

填空题

  • $\frac{2\rho g r^2}{3}$（$\rho$ 为液体密度）

解析：取深度 $x$ 处厚度为 $dx$ 的薄层，面积为 $\pi (r^2 - x^2)$，压强为 $\rho g x$，$P = \int_0^r \rho g x \cdot \pi (r^2 - x^2) dx = \frac{2\rho g r^2}{3}$。

  • $\frac{\rho g}{2}(h_2^2 - h_1^2)$

解析：$W = \int_{h_1}^{h_2} \rho g x \cdot A(x) dx$（具体表达式取决于容器形状）。

解答题

  • 建立坐标系：锥顶向下，锥口为原点。

深度为 $x$ 处，半径 $r(x) = \frac{R}{H}(H - x)$，截面积 $A(x) = \pi r^2 = \pi \frac{R^2}{H^2} (H - x)^2$。

$W = \int_0^H \rho g x \cdot \pi \frac{R^2}{H^2} (H - x)^2 dx = \frac{\pi \rho g R^2 H^2}{12}$

  • $W = \int_0^{0.2} 100x dx = 100 \cdot \frac{0.2^2}{2} = 2$ 焦耳

综合应用

解答题

  • 交点为 $x = 0$ 和 $x = 1$。

$V = \int_0^1 \pi [(2x - x^2)^2 - (x^2)^2] dx = \pi \int_0^1 (4x^2 - 4x^3 + x^4 - x^4) dx = \pi \int_0^1 (4x^2 - 4x^3) dx = \pi [\frac{4x^3}{3} - x^4]_0^1 = \frac{\pi}{3}$

  • 被积函数为 $\sqrt{1 + \cos x}$ 在 $[0, \frac{\pi}{2}]$ 上

$s = \int_0^{\pi/2} \sqrt{1 + \cos x} dx = \int_0^{\pi/2} \sqrt{2\cos^2 \frac{x}{2}} dx = \int_0^{\pi/2} \sqrt{2} \cos \frac{x}{2} dx = 2\sqrt{2} \sin \frac{x}{2} |_0^{\pi/2} = 2\sqrt{2}$

  • 在细杆上距质点 $x$ 处取一小段 $dx$，质量为 $\rho dx$

$F = \int_0^l G \frac{m \cdot \rho}{x^2} dx = Gm\rho \int_0^l \frac{dx}{x^2}$（这个积分是发散的，需要在杆的右端点截断）

实际上，细杆对端点处质点的引力需用积分定义求解。
