# 第16周：练习题目

## 无条件极值与判别法

### 选择题
1. 点 $(0,0)$ 是函数 $z = x^2 + y^2$ 的（ ）
   A. 极大值点
   B. 极小值点
   C. 鞍点
   D. 非驻点

2. 设 $z = f(x,y)$ 在驻点 $(x_0,y_0)$ 处 $A = f_{xx}$，$B = f_{xy}$，$C = f_{yy}$。若 $AC - B^2 < 0$，则（ ）
   A. $(x_0,y_0)$ 是极大值点
   B. $(x_0,y_0)$ 是极小值点
   C. $(x_0,y_0)$ 不是极值点
   D. 无法判断

3. 函数 $z = xy$ 在点 $(0,0)$ 处（ ）
   A. 取极大值
   B. 取极小值
   C. 是驻点但不是极值点
   D. 不是驻点

### 填空题
1. 函数 $z = x^2 + y^2 - 2x - 4y + 5$ 的极小值为 __________

2. 函数 $z = 1 - \sqrt{x^2+y^2}$ 的极大值为 __________（此函数在 $(0,0)$ 处偏导数不存在）

3. 函数 $z = e^{2x}\left(x + y^2 + 2y\right)$ 的驻点为 __________

### 解答题
1. 求 $z = x^3 - 4x^2 + 2xy - y^2$ 的极值。

2. 求 $z = x^3 + y^3 - 3x^2 - 3y^2$ 的极值。

3. 求 $z = x^2 + xy + y^2 - 3x - 6y$ 的极值。

4. 求 $z = \ln\left(1 + x^2 + y^2\right)$ 的极值。

5. 已知 $z = x^3 + y^3 + ax^2 + by^2 + c$ 在点 $(1, 1)$ 处取得极小值 $2$，求常数 $a$、$b$、$c$。

6. 求 $z = \sin x + \cos y + \cos(x - y)$（$0 \leq x \leq \frac{\pi}{2}$，$0 \leq y \leq \frac{\pi}{2}$）的极值（先求内点驻点）。

## 闭区域上的最值

### 选择题
1. 函数 $z = x^2 - y^2$ 在闭区域 $x^2 + y^2 \leq 1$ 上的最大值为（ ）
   A. $1$
   B. $\frac{1}{2}$
   C. $2$
   D. $0$

2. 函数 $z = xy$ 在闭区域 $x \geq 0$，$y \geq 0$，$x + y \leq 1$ 上的最大值为（ ）
   A. $1$
   B. $\frac{1}{4}$
   C. $\frac{1}{2}$
   D. $\frac{1}{8}$

3. 闭区域上的连续函数取得最大值的点（ ）
   A. 一定在区域内部
   B. 一定在边界上
   C. 可能在内部也可能在边界上
   D. 一定是驻点

### 填空题
1. $z = x + y$ 在区域 $x^2 + y^2 \leq 1$ 上的最大值为 __________

2. $z = x^2 y$（$x \geq 0$，$y \geq 0$，$x + y \leq 3$）的最大值为 __________

3. 函数 $z = x^2 + y^2$ 在区域 $x^2 + 4y^2 \leq 4$ 上的最小值为 __________

### 解答题
1. 求 $z = x^2 + y^2 - xy + x + y$ 在闭区域 $x \leq 0$，$y \leq 0$，$x + y \geq -3$ 上的最大值与最小值。

2. 求 $z = x^2 y(2 - x - y)$ 在闭区域 $D: x \geq 0$，$y \geq 0$，$x + y \leq 6$ 上的最大值与最小值。

3. 求 $z = 1 - x^2 - y^2$ 在闭区域 $x^2 + y^2 \leq 4$ 上的最大值与最小值。

4. 求 $z = x^2 + y^2$ 在闭区域 $x^2 + y^2 \leq 4$（即圆盘）上的最大值，并说明最小值为何不需要计算边界即可确定。

5. 求 $f(x, y) = 4x + 2y$ 在圆域 $x^2 + y^2 \leq 25$ 上的最大值（提示：在边界 $x^2 + y^2 = 25$ 上用代入法或拉格朗日乘数法）。

6. 求 $z = x^2 - xy + y^2$ 在闭区域 $|x| \leq 1$，$|y| \leq 1$ 上的最大值与最小值。

## 条件极值与拉格朗日乘数法

### 选择题
1. 用拉格朗日乘数法求 $f(x,y)$ 在 $\varphi(x,y)=0$ 下的极值时，拉格朗日函数为（ ）
   A. $L = f + \lambda\varphi$
   B. $L = f - \varphi$
   C. $L = \lambda f + \varphi$
   D. $L = f\varphi$

2. $f(x,y) = x + y$ 在约束 $x^2 + y^2 = 1$ 下的最大值为（ ）
   A. $1$
   B. $\sqrt{2}$
   C. $2$
   D. $\frac{1}{2}$

3. 函数 $z = xy$ 在约束 $x + y = 2$ 下的最大值为（ ）
   A. $1$
   B. $2$
   C. $\frac{1}{2}$
   D. 不存在

### 填空题
1. $f(x,y) = 2x + 3y$ 在 $x^2 + y^2 = 1$ 下的最大值为 __________

2. 抛物线 $y = x^2$ 上到点 $(0, 2)$ 距离最近的点为 __________

3. $f(x,y,z) = x + y + z$ 在 $x^2 + y^2 + z^2 = 3$ 上的最大值为 __________

### 解答题
1. 用拉格朗日乘数法求 $f(x,y) = xy$ 在约束 $x^2 + y^2 = 2$ 下的最大值与最小值。

2. 求表面积为 $54\ \text{m}^2$ 的长方体（三棱均为正数）体积的最大值。

3. 求原点到曲面 $(x - y)^2 - z^2 = 1$ 的最短距离。

4. 求函数 $u = x + y + z$ 在约束 $\frac{1}{x} + \frac{1}{y} + \frac{1}{z} = 1$（$x > 0$，$y > 0$，$z > 0$）下的最小值。

5. 在第一卦限内作椭球面 $\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1$ 的切平面，使切平面与三坐标面围成的四面体体积最小，求切点坐标。

6. 求 $f(x,y) = x^2 + y^2 - 2x - 2y$ 在约束区域 $x + y \leq 2$ 上的最小值（提示：先求无条件极值，判断其是否在约束区域内；若不在，再考虑边界 $x + y = 2$）。

## 综合应用题

1. 已知矩形的周长为 $2p$，将它绕其一边旋转而构成旋转体，问矩形的长与宽各为多少时旋转体体积最大？

2. 将正数 $a$ 分成三个正数 $x$、$y$、$z$ 之和，使 $x^2 + y^2 + z^2$ 最小，求这三个数及最小值。

3. 求内接于半径为 $R$ 的球（体积一定）且体积最大的圆柱体的高与底半径。

4. 某工厂生产两种产品，产量分别为 $x$、$y$（单位：千件），总成本函数 $C(x, y) = x^2 + 2y^2 - xy + 8$（单位：万元）。若两种产品的总产量为 10 千件，求成本最小的产量分配及最小成本。

5. 求 $z = f(x,y) = x^2 + y^2$ 在曲线约束 $\varphi(x,y) = x^3 - xy + y^3 - x - y = 0$ 上的可能极值点（只需列出拉格朗日方程组，不必求解全部）。

6. 在椭圆 $x^2 + 4y^2 = 4$ 上求一点，使其到直线 $2x + 3y - 6 = 0$ 的距离最短，并求最短距离。

7. 证明：对任意正数 $a$、$b$，有 $\frac{a^2 + b^2}{2} \geq ab$（提示：求 $f(x,y) = xy$ 在 $x^2 + y^2 = a^2 + b^2$ 约束下的最大值，或用 $f(x,y) = \frac{x^2+y^2}{2}$ 在 $xy = ab$ 约束下的最小值）。

8. 求函数 $u = \ln x + \ln y + \ln z$ 在约束 $x + y + z = 3$（$x, y, z > 0$）下的最大值，并由此证明：对任意正数 $a, b, c$，有 $\sqrt[3]{abc} \leq \frac{a+b+c}{3}$。
