学习内容

1. 多元复合函数的求导法则

1.1 链式法则

设 $z = f(u, v)$，$u = \phi(x, y)$，$v = \psi(x, y)$，则：

$$\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u} \frac{\partial u}{\partial x} + \frac{\partial z}{\partial v} \frac{\partial v}{\partial x}$$

$$\frac{\partial z}{\partial y} = \frac{\partial z}{\partial u} \frac{\partial u}{\partial y} + \frac{\partial z}{\partial v} \frac{\partial v}{\partial y}$$

1.2 全导数

设 $z = f(u, v, w)$，$u = u(t)$，$v = v(t)$，$w = w(t)$，则全导数：

$$\frac{dz}{dt} = \frac{\partial z}{\partial u} \frac{du}{dt} + \frac{\partial z}{\partial v} \frac{dv}{dt} + \frac{\partial z}{\partial w} \frac{dw}{dt}$$

2. 隐函数求导

2.1 隐函数存在定理

设 $F(x, y) = 0$，若在点 $(x_0, y_0)$ 的邻域内满足：

  • $F_x$ 和 $F_y$ 连续
  • $F(x_0, y_0) = 0$
  • $F_y(x_0, y_0) \neq 0$

则在 $x_0$ 的某邻域内唯一存在一个连续可导的函数 $y = f(x)$，使得 $F(x, f(x)) = 0$。

2.2 隐函数求导公式

由 $F(x, y) = 0$，两端对 $x$ 求导：

$$\frac{dy}{dx} = -\frac{F_x}{F_y}$$

对于 $F(x, y, z) = 0$：

$$\frac{\partial z}{\partial x} = -\frac{F_x}{F_z}, \quad \frac{\partial z}{\partial y} = -\frac{F_y}{F_z}$$

3. 方向导数与梯度

3.1 方向导数

设 $\vec{l} = (\cos \alpha, \cos \beta)$ 为方向，则

$$\frac{\partial f}{\partial \vec{l}} = f_x \cos \alpha + f_y \cos \beta$$

3.2 梯度

$$\nabla f = (f_x, f_y)$$

梯度方向是函数增长最快的方向，沿梯度方向的方向导数等于梯度的大小。

4. 极值与条件极值

4.1 二元函数极值

设 $f(x, y)$ 在 $(x_0, y_0)$ 的某邻域内有定义，若对邻域内任意点 $(x, y)$ 都有 $f(x, y) \leq f(x_0, y_0)$（或 $\geq$），则称 $(x_0, y_0)$ 为极大值点（或极小值点）。

必要条件：$f_x = 0$，$f_y = 0$。

充分条件：设 $A = f_{xx}$，$B = f_{xy}$，$C = f_{yy}$，则：

  • $AC - B^2 > 0$ 时有极值（$A < 0$ 时为极大值，$A > 0$ 时为极小值）
  • $AC - B^2 < 0$ 时无极值
  • $AC - B^2 = 0$ 时需进一步讨论

4.2 条件极值与拉格朗日乘数法

求 $z = f(x, y)$ 在约束条件 $g(x, y) = 0$ 下的极值。

构造拉格朗日函数：$L(x, y, \lambda) = f(x, y) + \lambda g(x, y)$

解方程组：

$$\begin{cases} f_x + \lambda g_x = 0 \\ f_y + \lambda g_y = 0 \\ g(x, y) = 0 \end{cases}$$

5. 偏导数的应用

5.1 几何应用

曲面 $z = f(x, y)$ 在点 $(x_0, y_0, z_0)$ 处的切平面方程：

$$z - z_0 = f_x(x_0, y_0)(x - x_0) + f_y(x_0, y_0)(y - y_0)$$

5.2 最值问题

在实际问题中，求函数在有界闭区域上的最大最小值，需考虑边界上的值和内部极值。
