### 填空题

3. **答案：$\left(\dfrac{1}{2}, -1\right)$**

### 解答题

   $A = 6x - 6$，$B = 0$，$C = 6y - 6$。
   $(0,0)$：$AC = 36 > 0$，$A < 0$，极大值 $0$；$(2,2)$：$AC = 36 > 0$，$A = 6 > 0$，极小值 $z(2,2) = 8 + 8 - 12 - 12 = -8$；$(0,2)$、$(2,0)$：$AC < 0$，非极值

3. **解**：$z_x = 2x + y - 3 = 0$，$z_y = x + 2y - 6 = 0$，解得 $(0, 3)$。

## 闭区域上的最值

### 选择题
1. **答案：A**
   解析：内部驻点 $(0,0)$ 处 $z = 0$（鞍点）；边界 $x^2+y^2=1$ 上 $z = \cos^2\theta - \sin^2\theta = \cos 2\theta$，最大值 $1$（$\theta = 0$）

2. **答案：B**
   解析：边界 $x + y = 1$ 上 $xy = x(1 - x)$，在 $x = \frac{1}{2}$ 处最大 $\frac{1}{4}$；另两边上为 $0$

3. **答案：C**
   解析：闭区域上连续函数必有最值，最值点可能在内部（驻点或不可导点）也可能在边界上

3. **答案：$0$**

### 选择题

2. **答案：B**
   解析：由柯西不等式，$x + y \leq \sqrt{2}\cdot\sqrt{x^2+y^2} = \sqrt2$，在 $x = y = \frac{\sqrt2}{2}$ 处取得

3. **答案：A**
   解析：$y = 2 - x$，$xy = x(2-x)$ 在 $x = 1$ 处最大值 $1$（或用拉格朗日乘数法）

### 填空题
1. **答案：$\sqrt{13}$**
   解析：$\nabla f = \lambda\nabla g$：$2 = 2\lambda x$，$3 = 2\lambda y$，得 $x = \frac{2}{\lambda}$，$y = \frac{3}{\lambda}$，代入 $x^2+y^2=1$ 得 $\lambda = \pm\sqrt{13}$；$\lambda = -\sqrt{13}$ 时 $f = \sqrt{13}$
   （即 $(x,y) = \left(\frac{2}{\sqrt{13}}, \frac{3}{\sqrt{13}}\right)$ 处最大值 $f = \frac{4+9}{\sqrt{13}} = \sqrt{13}$）

2. **答案：$\left(\pm\dfrac{\sqrt6}{2}, \dfrac{3}{2}\right)$**
   解析：最小化 $d^2 = x^2 + (x^2 - 2)^2 = x^4 - 3x^2 + 4$，$d'$：$4x^3 - 6x = 0$，$x^2 = \frac{3}{2}$。
   最近距离 $d = \sqrt{\frac32 + \frac14} = \frac{\sqrt7}{2}$

3. **答案：$3$**
   解析：$L = x+y+z + \lambda(x^2+y^2+z^2-3)$：$1 + 2\lambda x = 0$ 等三式给出 $x = y = z$，代入约束 $x = y = z = 1$，最大值 $3$

### 解答题
1. **解**：$L = xy + \lambda(x^2 + y^2 - 2)$：$y + 2\lambda x = 0$，$x + 2\lambda y = 0$。
   两式分别乘 $x$、$y$ 后相加：$2xy + 2\lambda(x^2+y^2) = 0$，即 $xy = -\lambda \cdot 2 = -2\lambda$。
   又由两式消去 $\lambda$：$y^2 - x^2 = 0$（$\lambda \neq 0$），$x = \pm y$。
   $x = y$：$x = \pm 1$，$xy = 1$；$x = -y$：$x = \pm 1$，$xy = -1$。
   故最大值 $1$（在 $(1,1)$、$(-1,-1)$），最小值 $-1$（在 $(1,-1)$、$(-1,1)$）

2. **解**：设三棱 $x, y, z > 0$，约束 $2(xy + yz + zx) = 54$，即 $xy + yz + zx = 27$，目标 $V = xyz$。
   $L = xyz + \lambda(xy + yz + zx - 27)$：
   $yz + \lambda(y+z) = 0$，$xz + \lambda(x+z) = 0$，$xy + \lambda(x+y) = 0$。
   前两式相减：$(y - x)z + \lambda(y - x) = (y-x)(z+\lambda) = 0$，同理可得 $x = y = z$。
   代入：$3x^2 = 27$，$x = 3$，即 $x = y = z = 3$。
   最大体积 $V = 27\ \text{m}^3$（正方体）

3. **解**：最小化 $f = x^2 + y^2 + z^2$，约束 $g = (x-y)^2 - z^2 - 1 = 0$。
   $\nabla f = \mu\nabla g$：$2x = 2\mu(x - y)$，$2y = -2\mu(x-y)$，$2z = -2\mu z$。
   前两式相加：$x + y = 0$；第三式：$z(1 + \mu) = 0$。
   取 $z = 0$：约束为 $(x - y)^2 = 1$，结合 $y = -x$ 得 $x = \pm\frac{1}{2}$，$f = \frac{1}{2}$；
   取 $\mu = -1$：推出 $y = 2x$ 与 $x = 2y$，即 $x = y = 0$，代入约束 $-z^2 = 1$ 无解，舍去。
   最短距离 $d = \sqrt{\frac12} = \frac{\sqrt2}{2}$

4. **解**：$L = x + y + z + \lambda\left(\frac{1}{x} + \frac{1}{y} + \frac{1}{z} - 1\right)$。
   $1 - \frac{\lambda}{x^2} = 0$，$1 - \frac{\lambda}{y^2} = 0$，$1 - \frac{\lambda}{z^2} = 0$，得 $x = y = z = \sqrt\lambda$。
   代入约束：$\frac{3}{\sqrt\lambda} = 1$，$x = y = z = 3$。
   最小值 $u = 9$（由背景知为最小：如 $x \to 0^+$ 时 $u \to +\infty$）

5. **解**：切点 $(x_0, y_0, z_0)$ 处切平面为 $\frac{x_0x}{a^2} + \frac{y_0y}{b^2} + \frac{z_0z}{c^2} = 1$，三截距为 $\frac{a^2}{x_0}, \frac{b^2}{y_0}, \frac{c^2}{z_0}$，四面体体积
   $$V = \frac{a^2b^2c^2}{6x_0y_0z_0}$$
   最小化 $V$ 等价于最大化 $x_0y_0z_0$。拉格朗日：$yz_0 + \lambda\frac{2x_0}{a^2} = 0$ 等三式，解得 $x_0 = \frac{a}{\sqrt3}$，$y_0 = \frac{b}{\sqrt3}$，$z_0 = \frac{c}{\sqrt3}$。
   此时最小体积 $V = \frac{\sqrt3}{2}abc$

6. **解**：无条件极小值点：$z = (x-1)^2 + (y-1)^2 - 2$ 在 $(1,1)$ 处取最小 $-2$。
   检验约束：$x + y = 2 \leq 2$，点 $(1,1)$ 恰在约束边界上，属于允许区域，故最小值就是 $-2$（在 $(1,1)$ 取得），无需再考察边界内部其它点。
   （若约束为严格 $x + y < 2$ 则需另行讨论边界 $x + y = 2$ 上的条件极值，结果仍趋于此值）

## 综合应用题

1. **解**：设矩形两边为 $x$（旋转轴）与 $y$，约束 $x + y = p$，旋转体（圆柱）体积 $V = \pi y^2 x = \pi y^2(p - y)$。
   $\frac{dV}{dy} = \pi y(2p - 3y) = 0 \Rightarrow y = \frac{2p}{3}$，$x = \frac{p}{3}$。
   故以长 $\frac{p}{3}$ 的一边为轴、宽 $\frac{2p}{3}$ 时体积最大，最大体积 $V = \pi\cdot\frac{4p^2}{9}\cdot\frac{p}{3} = \frac{4\pi p^3}{27}$

2. **解**：$L = x^2 + y^2 + z^2 + \lambda(x + y + z - a)$：
   $2x + \lambda = 0$，$2y + \lambda = 0$，$2z + \lambda = 0$，得 $x = y = z = \frac{a}{3}$。
   最小值 $x^2 + y^2 + z^2 = 3\cdot\frac{a^2}{9} = \frac{a^2}{3}$。
   （当某一变量趋于 $a$ 时平方和趋于 $a^2 > \frac{a^2}{3}$，故为最小）

3. **解**：设圆柱高 $h$、底半径 $r$，轴截面关系：$r^2 + \frac{h^2}{4} = R^2$，即 $r^2 = R^2 - \frac{h^2}{4}$。
   $V = \pi r^2 h = \pi h\left(R^2 - \frac{h^2}{4}\right)$，$\frac{dV}{dh} = \pi\left(R^2 - \frac{3h^2}{4}\right) = 0$，$h = \frac{2R}{\sqrt3}$。
   $r = R\sqrt{1 - \frac{1}{3}} = R\sqrt{\frac{2}{3}}$，最大体积 $V = \frac{4\sqrt3}{9}\pi R^3$

4. **解**：约束 $x + y = 10$，代入：$C = (10 - y)^2 + 2y^2 - (10-y)y + 8 = 4y^2 - 30y + 108$。
   $\frac{dC}{dy} = 8y - 30 = 0$，$y = 3.75$，$x = 6.25$。
   最小成本 $C = 4 \times 14.0625 - 112.5 + 108 = 51.75$ 万元。
   即产品一 6.25 千件、产品二 3.75 千件时成本最小，为 51.75 万元

5. **解**：作 $L = x^2 + y^2 + \lambda\left(x^3 - xy + y^3 - x - y\right)$，拉格朗日方程组：
   $$\begin{cases} 2x + \lambda(3x^2 - y - 1) = 0 \\ 2y + \lambda(3y^2 - x - 1) = 0 \\ x^3 - xy + y^3 - x - y = 0 \end{cases}$$
   满足该方程组的 $(x, y, \lambda)$ 对应的点 $(x,y)$ 即为可能极值点

6. **解**：最小化 $d^2 = \frac{(2x+3y-6)^2}{13}$（等价于最小化 $(2x+3y-6)^2$），约束 $x^2 + 4y^2 = 4$。
   $L = (2x+3y-6)^2 + \lambda(x^2 + 4y^2 - 4)$：
   $4(2x+3y-6) + 2\lambda x = 0$，$6(2x+3y-6) + 8\lambda y = 0$。
   两式相除消去 $2x + 3y - 6$：$\frac{4}{6} = \frac{2\lambda x}{8\lambda y}$，得 $x = \frac{8y}{3}$。
   代入约束：$\frac{64}{9}y^2 + 4y^2 = 4$，$y^2 = \frac{9}{25}$，$y = \pm\frac{3}{5}$。
   $y = \frac35$，$x = \frac85$：$|2x+3y-6| = 1$，距离 $\frac{1}{\sqrt{13}}$；
   $y = -\frac35$：$|2x+3y-6| = 11$，距离 $\frac{11}{\sqrt{13}}$。
   故最短距离点为 $\left(\frac{8}{5}, \frac{3}{5}\right)$，最短距离 $\frac{1}{\sqrt{13}} = \frac{\sqrt{13}}{13}$

7. **解**：考虑 $f(x,y) = xy$ 在约束 $x^2 + y^2 = a^2 + b^2$ 下的最大值。
   由拉格朗日乘数法（同解答题1），最大值为 $\frac{a^2+b^2}{2}$（在 $x = y = \sqrt{\frac{a^2+b^2}{2}}$ 处取得）。
   而点 $(a, b)$ 满足该约束，故 $ab \leq \frac{a^2+b^2}{2}$，即 $\frac{a^2+b^2}{2} \geq ab$，等号当且仅当 $a = b$

8. **解**：$L = \ln x + \ln y + \ln z + \lambda(x + y + z - 3)$：
   $\frac{1}{x} + \lambda = 0$，$\frac{1}{y} + \lambda = 0$，$\frac{1}{z} + \lambda = 0$，得 $x = y = z = 1$，最大值 $\ln 1 + \ln 1 + \ln 1 = 0$。
   对任意正数 $a, b, c$，令 $s = a + b + c$，取 $x = \frac{3a}{s}$，$y = \frac{3b}{s}$，$z = \frac{3c}{s}$（满足 $x+y+z = 3$）：
   $$0 \geq \ln x + \ln y + \ln z = \ln\frac{27abc}{s^3} \Rightarrow abc \leq \frac{s^3}{27} \Rightarrow \sqrt[3]{abc} \leq \frac{a+b+c}{3}$$
