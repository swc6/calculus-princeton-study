# 第16周：多元函数的极值与最值

## 学习目标
- 理解多元函数极值的概念，掌握极值存在的必要条件
- 熟练掌握二元函数极值的充分条件判别法（$AC - B^2$ 判别法）
- 掌握求有界闭区域上连续函数最大值与最小值的方法

- 会求解简单几何与经济应用中的最值问题

## 学习内容

### 1. 多元函数的极值

#### 1.1 极值的定义
设 $f$ 在点 $P_0(x_0, y_0)$ 的某邻域内有定义。若对该邻域内异于 $P_0$ 的任何点 $P$ 都有 $f(P) < f(P_0)$（或 $f(P) > f(P_0)$），则称 $f$ 在 $P_0$ 取得**极大值**（或**极小值**）$f(P_0)$，$P_0$ 称为极值点。

注意：极值是**局部性**概念，且只与邻域内的点比较（不要求邻域内每点严格大于/小于，比较的是异于 $P_0$ 的点）。

#### 1.2 极值的必要条件
若 $f$ 在 $P_0$ 处可微且取得极值，则
$$f_x(x_0, y_0) = 0, \qquad f_y(x_0, y_0) = 0$$
使两个偏导数同时为零的点称为 $f$ 的**驻点**。

注意：
- 可微函数的极值点必为驻点，但驻点未必是极值点（如 $z = xy$ 在 $(0,0)$ 驻点处是鞍点）；
- 偏导数不存在的点也可能是极值点（如 $z = \sqrt{x^2+y^2}$ 在 $(0,0)$ 取极小值但偏导不存在）。

#### 1.3 极值的充分条件（判别法）
设 $f$ 在驻点 $P_0(x_0, y_0)$ 的某邻域内有二阶连续偏导数。记
$$A = f_{xx}(P_0), \qquad B = f_{xy}(P_0), \qquad C = f_{yy}(P_0)$$
则：
1. 若 $AC - B^2 > 0$ 且 $A > 0$，则 $P_0$ 为**极小值点**；
2. 若 $AC - B^2 > 0$ 且 $A < 0$，则 $P_0$ 为**极大值点**；
3. 若 $AC - B^2 < 0$，则 $P_0$ **不是极值点**（鞍点）；
4. 若 $AC - B^2 = 0$，**不能断定**，需用定义或其它方法讨论。

#### 1.4 典型例题
例：求 $z = x^3 + y^3 - 3xy$ 的极值。
- $z_x = 3x^2 - 3y = 0$，$z_y = 3y^2 - 3x = 0$，得驻点 $(0,0)$ 与 $(1,1)$；
- $A = 6x$，$B = -3$，$C = 6y$；
- $(0,0)$：$AC - B^2 = 0 - 9 = -9 < 0$，非极值点；
- $(1,1)$：$AC - B^2 = 36 - 9 = 27 > 0$，$A = 6 > 0$，为极小值点，极小值 $z(1,1) = 1 + 1 - 3 = -1$。

例：求 $z = x^3 - y^3 + 3x^2 + 3y^2 - 9x$ 的极值。
- $z_x = 3x^2 + 6x - 9 = 3(x+3)(x-1) = 0$，$z_y = -3y^2 + 6y = -3y(y-2) = 0$；
- 驻点：$(1,0)$，$(1,2)$，$(-3,0)$，$(-3,2)$；
- $A = 6x + 6$，$B = 0$，$C = -6y + 6$；
- $(1,0)$：$AC - B^2 = 12 \times 6 = 72 > 0$，$A = 12 > 0$，极小值 $z(1,0) = -5$；
- $(1,2)$：$AC - B^2 = 12 \times (-6) < 0$，非极值；
- $(-3,0)$：$AC - B^2 = -12 \times 6 < 0$，非极值；
- $(-3,2)$：$AC - B^2 = -12 \times (-6) = 72 > 0$，$A = -12 < 0$，极大值 $z(-3,2) = 31$。

### 2. 有界闭区域上的最大值与最小值

#### 2.1 求法步骤
设 $f$ 在有界闭区域 $D$ 上连续，则必取得最大值与最小值：
1. 求 $D$ 内部所有驻点及偏导数不存在的点，计算函数值；
2. 求 $D$ 边界上的最大值、最小值（把边界代入约束，化为一元问题或用拉格朗日乘数法）；
3. 比较所有候选值，最大者为最大值，最小者为最小值。

#### 2.2 典型例题
例：求 $z = x^2 y(4 - x - y)$ 在闭区域 $D: x \geq 0$，$y \geq 0$，$x + y \leq 6$ 上的最大值与最小值。
- 内部驻点：$z = 4x^2y - x^3y - x^2y^2$；
  $z_x = 8xy - 3x^2y - 2xy^2 = xy(8 - 3x - 2y) = 0$，$z_y = 4x^2 - x^3 - 2x^2y = x^2(4 - x - 2y) = 0$；
  在 $D$ 内部（$x>0, y>0$）：$3x + 2y = 8$，$x + 2y = 4$，解得 $x = 2$，$y = 1$，$z(2,1) = 4$；
- 边界 $x = 0$ 或 $y = 0$：$z = 0$；边界 $x + y = 6$：$z = x^2(6-x)(-2) \leq 0$，最小在内部端点比较，$z = -2x^2(6-x)$，$x \in [0,6]$，在 $x = 4$ 处取最小 $-2\times16\times2 = -64$；
- 比较得：最大值 $z(2,1) = 4$，最小值 $z(4,2) = -64$。

#### 2.3 实际问题的最值
若按问题性质知最值必在区域内部达到，而内部驻点唯一，则该驻点即为所求最值点，不必判别。

### 3. 条件极值与拉格朗日乘数法

#### 3.1 条件极值的概念
求 $f(x, y)$ 在约束条件 $\varphi(x, y) = 0$ 下的极值，称为**条件极值**。两种处理方式：
- 代入法：从约束解出 $y = y(x)$ 代入，化为一元极值（能解出时较方便）；
- 拉格朗日乘数法（一般方法）。

#### 3.2 拉格朗日乘数法
求 $f(x, y)$ 在 $\varphi(x, y) = 0$ 下的极值：作拉格朗日函数
$$L(x, y, \lambda) = f(x, y) + \lambda\varphi(x, y)$$
令
$$L_x = f_x + \lambda\varphi_x = 0, \qquad L_y = f_y + \lambda\varphi_y = 0, \qquad \varphi(x,y) = 0$$
解出 $(x, y, \lambda)$，则 $(x, y)$ 就是条件极值的候选点。

推广：$n$ 个变量、$m$ 个约束时引入 $m$ 个乘数，如求 $f(x,y,z)$ 在 $\varphi(x,y,z)=0$ 下的极值：
$$L = f + \lambda\varphi, \qquad L_x = L_y = L_z = 0,\ \varphi = 0$$

#### 3.3 典型例题
例：求 $f(x,y) = xy$ 在 $x + y = 1$ 下的最大值。
- $L = xy + \lambda(x + y - 1)$；
- $L_x = y + \lambda = 0$，$L_y = x + \lambda = 0$ $\Rightarrow$ $x = y$；代入约束：$x = y = \frac{1}{2}$；
- $f\left(\frac{1}{2}, \frac{1}{2}\right) = \frac{1}{4}$。由问题背景知该值为最大值。

例（经典）：表面积一定、体积最大的长方体是正方体。设三棱为 $x, y, z$，约束 $xy + yz + zx = 6$，目标 $V = xyz$：
- $L = xyz + \lambda(xy + yz + zx - 6)$；
- $yz + \lambda(y + z) = 0$，$xz + \lambda(x + z) = 0$，$xy + \lambda(x + y) = 0$；
- 前两式相减：$(y-x)z + \lambda(y-x) = (y-x)(z+\lambda) = 0$；同理可得 $x = y = z$（或 $z = -\lambda$ 等退化情形，联立可排除）；
- 代入约束：$3x^2 = 6$，$x = \sqrt{2}$，即 $x = y = z = \sqrt{2}$，$V = 2\sqrt{2}$ 为最大体积。

#### 3.4 两个约束条件的情形
求 $f(x,y,z)$ 在 $\varphi_1 = 0$、$\varphi_2 = 0$ 下的极值：
$$L = f + \lambda\varphi_1 + \mu\varphi_2$$
令 $L_x = L_y = L_z = L_\lambda = L_\mu = 0$。

例：求 $f = x + 2y + 3z$ 在 $x + y + z = 6$ 与 $x^2 + y^2 + z^2 = 14$ 交线上的最值... （此类题综合应用题中体现）

### 4. 最值问题的一般策略

| 问题类型 | 方法 |
|---|---|
| 无条件极值 | 驻点 + $AC - B^2$ 判别 |
| 闭区域最值 | 内部驻点值 + 边界最值，比较 |
| 条件极值（约束方程可解） | 代入法化为一元 |
| 条件极值（一般情形） | 拉格朗日乘数法 |
| 实际问题 | 驻点唯一 + 背景确定最值在内点达到 |

## 学习建议
- $AC - B^2$ 判别法只适用于**驻点**处，且 $AC - B^2 = 0$ 时失效
- 求闭区域最值时切勿忘记**边界**，边界问题常化为带约束的条件极值
- 拉格朗日乘数法只给出候选点，最终判定需结合问题背景或比较函数值
- 实际问题中利用"最值必存在且在内点达到 + 驻点唯一"可省去二阶判别
- 拉格朗日函数中方程组的消元技巧：先对称作差找 $x = y$ 类关系
