第13周：幂级数

学习目标

  • 理解幂级数的概念和收敛半径
  • 掌握幂级数收敛区间的求法
  • 理解幂级数的运算性质
  • 学会将函数展开成幂级数
  • 掌握幂级数在近似计算中的应用

学习内容

1. 幂级数的概念

1.1 定义

幂级数是形如 $\sum_{n=0}^{\infty} a_n (x - x_0)^n$ 的级数，其中 $a_n$ 为系数，$x_0$ 为展开点。

当 $x_0 = 0$ 时，为 $\sum_{n=0}^{\infty} a_n x^n$，称为麦克劳林级数。

1.2 收敛半径

对于幂级数 $\sum a_n x^n$，设 $\lim_{n \to \infty} |\frac{a_{n+1}}{a_n}| = \rho$ 或 $\lim_{n \to \infty} \sqrt[n]{|a_n|} = \rho$，则收敛半径 $R = \frac{1}{\rho}$。

  • $\rho = 0$ 时，$R = \infty$，级数在整个实数轴上收敛
  • $\rho = \infty$ 时，$R = 0$，级数仅在 $x = 0$ 处收敛
  • $0 < \rho < \infty$ 时，$R = \frac{1}{\rho}$

2. 收敛区间与收敛域

2.1 收敛区间的求法

对于 $\sum a_n (x - x_0)^n$：

  1. 求 $\rho = \lim |\frac{a_{n+1}}{a_n}|$ 或 $\rho = \lim \sqrt[n]{|a_n|}$
  2. 求 $R = \frac{1}{\rho}$
  3. 判断端点 $x_0 \pm R$ 处的敛散性

2.2 例题

  • 求 $\sum_{n=0}^{\infty} \frac{x^n}{n!}$ 的收敛域

- $\rho = \lim \frac{1/(n+1)!}{1/n!} = \lim \frac{1}{n+1} = 0$，$R = \infty$

- 对所有 $x \in (-\infty, +\infty)$ 收敛

  • 求 $\sum_{n=1}^{\infty} \frac{(x-2)^n}{n}$ 的收敛域

- $\rho = 1$，$R = 1$

- 区间为 $(1, 3)$

- $x = 3$ 时，$\sum \frac{1}{n}$ 发散；$x = 1$ 时，$\sum \frac{(-1)^n}{n}$ 收敛

- 收敛域为 $[1, 3)$

3. 幂级数的运算

3.1 四则运算

若 $\sum a_n x^n$ 和 $\sum b_n x^n$ 的收敛半径分别为 $R_1$ 和 $R_2$，则：

  • $\sum (a_n \pm b_n) x^n$ 的收敛半径 $\geq \min(R_1, R_2)$
  • $(\sum a_n x^n) \cdot (\sum b_n x^n)$ 的收敛半径 $\geq \min(R_1, R_2)$

3.2 分析运算

  • 幂级数在其收敛区间内可以逐项求导：$[\sum a_n x^n]' = \sum n a_n x^{n-1}$
  • 幂级数在其收敛区间内可以逐项积分：$\int \sum a_n x^n dx = \sum \frac{a_n}{n+1} x^{n+1}$
  • 求导或积分后收敛半径不变，端点处敛散性可能改变

4. 函数展开成幂级数

4.1 直接展开法

利用泰勒公式：$f(x) = \sum_{n=0}^{\infty} \frac{f^{(n)}(x_0)}{n!} (x - x_0)^n$

4.2 间接展开法

利用已知展开式和幂级数的运算性质。

常用展开式：

  • $e^x = \sum_{n=0}^{\infty} \frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \cdots$
  • $\sin x = \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n+1}}{(2n+1)!} = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots$
  • $\cos x = \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n}}{(2n)!} = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots$
  • $\ln(1+x) = \sum_{n=1}^{\infty} \frac{(-1)^{n-1} x^n}{n} = x - \frac{x^2}{2} + \frac{x^3}{3} - \cdots$（$|x| < 1$）
  • $(1+x)^\alpha = 1 + \alpha x + \frac{\alpha(\alpha-1)}{2!} x^2 + \cdots$（$|x| < 1$）

5. 幂级数的应用

5.1 近似计算

例：计算 $e$ 的值

$$e = \sum_{n=0}^{\infty} \frac{1}{n!}$$

取前 $n$ 项部分和作为近似值，误差小于余项。

5.2 积分计算

对于无法用初等函数表示的积分，可以展开为幂级数后逐项积分。

  • 熟记常用函数的幂级数展开式
  • 熟练掌握收敛半径的求法
  • 注意端点处敛散性的判断
  • 多做练习，积累间接展开的经验
