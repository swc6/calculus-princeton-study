第17周：多重积分

学习目标

  • 理解二重积分的概念和性质
  • 掌握二重积分在直角坐标系下的计算方法
  • 理解二重积分在极坐标系下的计算方法
  • 掌握三重积分的概念和计算
  • 理解多重积分的几何应用

学习内容

1. 二重积分的概念

1.1 定义

设 $f(x, y)$ 是平面有界闭区域 $D$ 上的有界函数，将 $D$ 任意分成 $n$ 个小区域 $\Delta \sigma_1, \Delta \sigma_2, \cdots, \Delta \sigma_n$，在每个小区域上取一点 $(x_i, y_i)$，作和 $\sum_{i=1}^n f(x_i, y_i) \Delta \sigma_i$。如果当各小区域的直径的最大值 $\lambda \to 0$ 时，这个和的极限存在，则称此极限为 $f(x, y)$ 在 $D$ 上的二重积分，记作 $\iint_D f(x, y) d\sigma$。

1.2 几何意义

当 $f(x, y) \geq 0$ 时，$\iint_D f(x, y) d\sigma$ 表示以 $D$ 为底、曲面 $z = f(x, y)$ 为顶的曲顶柱体的体积。

1.3 性质

  • 线性性：$\iint_D (af + bg) d\sigma = a \iint_D f d\sigma + b \iint_D g d\sigma$
  • 可加性：若 $D = D_1 \cup D_2$，$D_1 \cap D_2 = \emptyset$，则 $\iint_D f d\sigma = \iint_{D_1} f d\sigma + \iint_{D_2} f d\sigma$
  • 若在 $D$ 上 $f(x, y) \leq g(x, y)$，则 $\iint_D f d\sigma \leq \iint_D g d\sigma$
  • 估值不等式：若 $m \leq f(x, y) \leq M$，则 $m \cdot S_D \leq \iint_D f d\sigma \leq M \cdot S_D$
  • 中值定理：若 $f$ 连续，则存在 $(\xi, \eta) \in D$，使得 $\iint_D f d\sigma = f(\xi, \eta) \cdot S_D$

2. 二重积分的计算

2.1 直角坐标系

如果区域 $D$ 可以表示为 $a \leq x \leq b$，$\phi_1(x) \leq y \leq \phi_2(x)$，则：

$$\iint_D f(x, y) d\sigma = \int_a^b \left[ \int_{\phi_1(x)}^{\phi_2(x)} f(x, y) dy \right] dx$$

如果区域 $D$ 可以表示为 $c \leq y \leq d$，$\psi_1(y) \leq x \leq \psi_2(y)$，则：

$$\iint_D f(x, y) d\sigma = \int_c^d \left[ \int_{\psi_1(y)}^{\psi_2(y)} f(x, y) dx \right] dy$$

2.2 极坐标系

在极坐标系下，面积元素 $d\sigma = r dr d\theta$。如果区域 $D$ 可以表示为 $\alpha \leq \theta \leq \beta$，$r_1(\theta) \leq r \leq r_2(\theta)$，则：

$$\iint_D f(x, y) d\sigma = \int_\alpha^\beta \int_{r_1(\theta)}^{r_2(\theta)} f(r\cos\theta, r\sin\theta) r dr d\theta$$

3. 二重积分的应用

3.1 体积

曲顶柱体的体积 $V = \iint_D f(x, y) d\sigma$。

3.2 面积

平面区域 $D$ 的面积 $S = \iint_D 1 d\sigma$。

3.3 曲面面积

曲面 $z = f(x, y)$ 在区域 $D$ 上的面积 $A = \iint_D \sqrt{1 + f_x^2 + f_y^2} d\sigma$。

4. 三重积分

4.1 定义

类似二重积分，定义三元函数在空间区域 $\Omega$ 上的三重积分 $\iiint_\Omega f(x, y, z) dV$。

4.2 计算方法

在直角坐标系下：

$$\iiint_\Omega f(x, y, z) dV = \iint_{D_{xy}} \left[ \int_{z_1(x,y)}^{z_2(x,y)} f(x, y, z) dz \right] d\sigma$$

4.3 柱面坐标系

$x = r\cos\theta$，$y = r\sin\theta$，$z = z$，$dV = r dr d\theta dz$。

4.4 球面坐标系

$x = r\sin\varphi\cos\theta$，$y = r\sin\varphi\sin\theta$，$z = r\cos\varphi$，$dV = r^2 \sin\varphi dr d\varphi d\theta$。

5. 重积分的应用

5.1 质量

平面薄片的质量 $m = \iint_D \rho(x, y) d\sigma$。

5.2 质心

$\bar{x} = \frac{\iint_D x \rho d\sigma}{\iint_D \rho d\sigma}$，$\bar{y} = \frac{\iint_D y \rho d\sigma}{\iint_D \rho d\sigma}$。

5.3 转动惯量

$I_x = \iint_D y^2 \rho d\sigma$，$I_y = \iint_D x^2 \rho d\sigma$。

学习建议

  • 理解重积分的定义和几何意义
  • 熟练掌握在不同坐标系下计算重积分
  • 学会根据积分区域和被积函数的特点选择合适的坐标系
  • 注意交换积分次序的方法
