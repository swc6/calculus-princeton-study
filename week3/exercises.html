综合应用题

  • 求曲线$y = x^3 - 3x^2 + 2$在点$(1, 0)$处的切线方程和法线方程。
  • 已知物体的运动方程为$s = t^3 - 3t^2 + 2t$，求物体在$t = 2$时的速度和加速度。
  • 设生产$x$单位产品的成本函数为$C(x) = 100 + 0.01x^2$，求边际成本函数和当$x = 100$时的边际成本。
  • 求函数$f(x) = x^2 e^{-x}$的一阶导数和二阶导数。
  • 已知函数$f(x) = x^3 + ax^2 + bx + c$在$x = 1$处有极大值，在$x = 3$处有极小值，且$f(0) = 1$，求$a$、$b$、$c$的值。
  • 求函数$f(x) = \frac{x^2}{x + 1}$的导数，并求其在$x = 1$处的切线方程。
  • 求由方程$x^2 + y^2 - 2xy = 0$确定的隐函数$y = y(x)$的导数。
  • 求由参数方程$\begin{cases} x = 1 + t^2 \\ y = t^3 + 2t \end{cases}$确定的函数$y = y(x)$在$t = 1$处的切线方程。
  • 求函数$f(x) = \sin x \cos x$的$n$阶导数。
  • 证明：若函数$f(x)$在$x_0$处可导，则$f(x)$在$x_0$处连续。
