# 第19周：模拟测试与查漏补缺

## 学习目标
- 掌握考前冲刺阶段的三轮复习策略与时间规划方法
- 能够识别概念性、计算性、规范性三类常见失分点并针对性规避
- 学会按题型分值合理分配答题时间，掌握基本应试技巧
- 学会科学使用模拟测试：全真限时、判分复盘、错题归因
- 能借助薄弱环节自检清单准确定位漏洞并回炉相应周次材料

## 学习内容

### 1. 考前复习策略

#### 1.1 三轮复习法
- **第一轮（知识扫盲）**：对照第18周的公式清单和知识框架，逐模块自查"能不能默写、会不会使用"，把记不住的公式抄到卡片上随身记；发现的漏洞直接回看对应周次的 content 文件，不做难题
- **第二轮（题目强化）**：重做第1—18周的错题，重点做当年"看答案才懂"的题；本周完成两套模拟试卷的限时训练
- **第三轮（考前保温）**：考前1—2天只看错题本、公式卡片和易错点清单，做1—2道基础题保持手感，不做新难题、不熬夜

#### 1.2 资料使用建议
- 第18周 content 是"索引"：复习时按模块查阅，不必从头到尾通读
- 各周 exercises 是"题库"：以错题为主，会的题不必重复刷
- 本周模拟试卷是"体检"：严格按考试状态完成，用结果决定后续复习重点

### 2. 常见失分点分析

#### 2.1 概念性失分
- 混淆"$a^x$与$x^a$"、"$f'(x_0)$与$[f(x_0)]'$"、"$\ln|x|$漏绝对值"
- 极值点、驻点、拐点概念混淆；拐点只写横坐标不写点的坐标
- 反常积分不取极限直接代入；幂级数收敛域漏判端点
- 二元极值判别式$AC-B^2$的符号与结论对应关系记反
- **规避方法**：把第18周每个模块的"易错点提醒"做成检查清单，做题时对照执行

#### 2.2 计算性失分
- 复合函数求导漏乘链式因子；乘积、商的求导公式用错
- 定积分换元后忘记换上下限；分部积分符号出错
- 部分分式系数解错、通分时漏项；旋转体体积漏乘$\pi$或极坐标漏乘$r$
- **规避方法**：关键步骤落笔成文，不跳步心算；积分结果用"求导还原"验证，检验成本极低

#### 2.3 规范性失分
- 应用题（最值、面积、体积）不设变量、不写积分区间、不说明最值理由
- 解答题只写答案不写过程，中间步骤缺失导致按步扣分
- 未验证洛必达法则的适用条件就使用；级数判别不写所用判别法的名称和条件
- **规避方法**：按"设—列—解—答"四步作答；判别法先写条件再写结论

### 3. 答题时间分配建议

以"满分100分、建议用时120分钟"的试卷为基准（选择题每题4分共20分，填空题每题4分共20分，解答题6题共60分）：

| 阶段 | 题型 | 建议用时 | 要点 |
| --- | --- | --- | --- |
| 第一阶段 | 选择题（5题，20分） | 约20分钟 | 每题不超过5分钟，可用代入验证、排除法提速 |
| 第二阶段 | 填空题（5题，20分） | 约20分钟 | 计算定积分、极限时先判断类型再动笔 |
| 第三阶段 | 解答题前4题（约38分） | 约45分钟 | 多为基础综合题，力争稳拿大部分分数 |
| 第四阶段 | 解答题后2题（约22分） | 约25分钟 | 级数与多元题，写清判别法条件与步骤 |
| 收尾 | 全卷检查 | 约10分钟 | 核对抄写错误、漏号漏问、符号笔误 |

时间原则：
- 单题卡壳超过预算时间的一半（如选择题卡住3分钟）就先标记跳过，做完再回头
- 分值高的题优先保证步骤完整，即使算不完也要把已得的中间结果写出
- 预留检查时间写进计划，而不是"最后剩多少算多少"

### 4. 模拟测试使用方法

#### 4.1 测试流程
1. **全真环境**：安静环境、120分钟倒计时、只带笔和草稿纸，不查资料、不看答案
2. **按建议顺序作答**：先选择填空后解答，遵守时间预算
3. **立即判分**：对照 week19-solutions.md 按步给分，选择题、填空题错则该题0分，解答题按评分要点逐行给分
4. **记录成绩**：记下总分和各题得分，两张试卷间隔2—3天完成，比较进步与反复出错的点

#### 4.2 试卷分析三步法
- **归因**：每道丢分题标注原因——"概念不清""方法不会""计算失误""时间不够"四选一（可多选）
- **定位**：把"概念不清""方法不会"的题目对应回具体周次（如级数判别法回第12周，拉格朗日乘数法回第16周），重读 content 并重做该周相关练习
- **重测**：对做错的解答题，隔1—2天后遮住答案独立重做一遍，能完整写对才算过关

### 5. 薄弱环节自检清单

对照下列条目自测，"否"的条目即薄弱环节，按括号中的周次回炉：

- [ ] 能默写两个重要极限和7组常用等价无穷小，并知道等价替换只用于乘除（第2周）
- [ ] 能用洛必达法则处理$\dfrac{0}{0}$、$\dfrac{\infty}{\infty}$型极限，并先化简再求导（第2、6周）
- [ ] 能默写基本导数表，会链式法则、隐函数求导、参数方程求导（第3、5周）
- [ ] 会求单调区间、极值、凹凸区间、拐点及三种渐近线（第4、6周）
- [ ] 能叙述罗尔定理与拉格朗日中值定理的条件和结论，并用其证明简单不等式（第6周）
- [ ] 会凑微分、三角代换、分部积分，会部分分式分解并积分（第7—9周）
- [ ] 会用牛顿—莱布尼茨公式和变限积分求导，会用奇偶对称性简化定积分（第7、8周）
- [ ] 会求面积、旋转体体积、弧长，会判断反常积分敛散并计算简单反常积分（第10、11周）
- [ ] 会用比较、比值、莱布尼茨判别法判断敛散性，会区分绝对收敛与条件收敛（第12周）
- [ ] 会求幂级数收敛半径与收敛域（含端点），会做常用麦克劳林展开（第13周）
- [ ] 会用幂级数求和函数或进行近似计算（第14周）
- [ ] 会求多元函数偏导数、全微分，会用多元链式法则和隐函数求导公式（第15周）
- [ ] 会用$AC-B^2$判别二元极值，会用拉格朗日乘数法解条件极值（第16周）
- [ ] 会化直角坐标二重积分为累次积分，会交换积分次序，会用极坐标计算（第17周）

### 6. 冲刺阶段作息与心态
- 每天固定1—2小时高强度练习，优于零散长时间疲劳战
- 模拟测试成绩波动正常，重点看错题归因是否收敛（同类错误是否不再犯）
- 考前睡眠优先于刷题，公式卡片用于碎片时间回顾

## 学习建议
- 先用第5节自检清单完成一次"体检"，再决定复习顺序，避免平均用力
- 两套模拟试卷务必限时完成并按步判分，只对答案不分析等于白做
- 丢分题按"概念—方法—计算—时间"四类归因，针对性回炉对应周次
- 每天收尾时用5分钟默写当日复习模块的公式清单，巩固记忆
- 考前2天回归错题本和公式卡片，不做偏题怪题
- 保持平稳心态：模拟卷的意义是暴露问题，暴露越多，正式考试越稳
