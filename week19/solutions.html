第19周：模拟测试答案

第一部分：极限与微分

1. 求极限

  • (1) $\lim_{x \to 0} \frac{\tan x - \sin x}{x^3} = \frac{1}{2}$

解：$\tan x - \sin x = x + \frac{x^3}{3} + \cdots - (x - \frac{x^3}{6} + \cdots) = \frac{x^3}{2} + \cdots$，故极限为 $\frac{1}{2}$。

  • (2) $\lim_{x \to \infty} (\frac{x+1}{x-1})^x = e^2$

解：$\frac{x+1}{x-1} = 1 + \frac{2}{x-1}$，令 $t = x-1$，原式 $= (1 + \frac{2}{t})^{t+1} \to e^2$。

  • (3) $\lim_{x \to 0^+} x^{\sin x} = 1$

解：$\ln(x^{\sin x}) = \sin x \cdot \ln x \to 0 \cdot (-\infty)$，用洛必达或泰勒展开得 $0$，故原式 $= e^0 = 1$。

2. 求导数

  • (1) $y' = \frac{2}{\sin 2x \cos 2x} = \frac{4}{\sin 4x}$

解：$y' = \frac{1}{\tan 2x} \cdot \sec^2 2x \cdot 2 = \frac{2}{\sin 2x \cos 2x} = \frac{4}{\sin 4x}$。

  • (2) $y' = (x^2 + 1)^x (2x \ln(x^2 + 1) + \frac{2x^3}{x^2 + 1})$

解：$y = e^{x \ln(x^2+1)}$，$y' = e^{x \ln(x^2+1)} \cdot [\ln(x^2+1) + \frac{2x^2}{x^2+1}]$。

  • (3) $\frac{dy}{dx} = -\frac{2x + y}{x + 2y}$

解：$2x + y + xy' + 2yy' = 0$，$y' = -\frac{2x+y}{x+2y}$。

第二部分：积分

3. 计算不定积分

  • (1) $\int \frac{dx}{x \ln x} = \ln|\ln x| + C$

解：令 $u = \ln x$，$du = \frac{dx}{x}$，原式 $= \int \frac{du}{u} = \ln|u| + C = \ln|\ln x| + C$。

  • (2) $\int x^2 e^x dx = e^x(x^2 - 2x + 2) + C$

解：分部积分两次，$\int x^2 e^x dx = x^2 e^x - 2\int x e^x dx = x^2 e^x - 2(e^x(x-1)) = e^x(x^2-2x+2)$。

  • (3) $\int \frac{dx}{\sqrt{x^2 + a^2}} = \ln|x + \sqrt{x^2 + a^2}| + C$

解：三角换元 $x = a \tan t$ 或记为标准结果。

4. 计算定积分

  • (1) $\int_0^1 \frac{x}{1+x^2} dx = \frac{1}{2}\ln 2$

解：令 $u = 1+x^2$，$du = 2x dx$，原式 $= \frac{1}{2}\int_1^2 \frac{du}{u} = \frac{1}{2}\ln 2$。

  • (2) $\int_0^1 x \ln(x+1) dx = \frac{1}{2}$

解：分部积分 $= [\frac{x^2}{2}\ln(x+1)]_0^1 - \frac{1}{2}\int_0^1 \frac{x^2}{x+1}dx = \frac{\ln 2}{2} - \frac{1}{2}(\frac{x^2}{2} - x + \ln(x+1))|_0^1 = \frac{1}{2}$。

  • (3) $\int_0^1 \frac{dx}{\sqrt{4 - x^2}} = \frac{\pi}{6}$

解：令 $x = 2\sin t$，原式 $= \int_0^{\pi/6} dt = \frac{\pi}{6}$。

第三部分：级数

5. 判断敛散性

  • (1) $\sum_{n=1}^{\infty} \frac{n}{n^2 + 1}$：发散

解：$\frac{n}{n^2+1} \sim \frac{1}{n}$，由比较判别法知发散。

  • (2) $\sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n^2}$：绝对收敛

解：$\sum \frac{1}{n^2}$ 收敛，故绝对收敛。

6. 幂级数

  • (1) 收敛半径 $R=1$，收敛域 $[-1, 1)$

解：$\rho = 1$，$R=1$。在 $x=1$ 时 $\sum \frac{1}{n+1}$ 发散，在 $x=-1$ 时 $\sum \frac{(-1)^n}{n+1}$ 收敛。

  • (2) $\frac{1}{1+x} = \sum_{n=0}^{\infty} (-1)^n x^n$（$|x| < 1$）

解：利用几何级数公式 $\frac{1}{1-x} = \sum x^n$，将 $x$ 替换为 $-x$。

第四部分：多元函数微积分

7. 偏导数与全微分

  • (1) $\frac{\partial^2 z}{\partial x \partial y} = 4xy e^{x^2+y^2}$

解：$\frac{\partial z}{\partial y} = 2y e^{x^2+y^2}$，$\frac{\partial^2 z}{\partial x \partial y} = 2y \cdot e^{x^2+y^2} \cdot 2x = 4xy e^{x^2+y^2}$。

  • (2) $dz = (3x^2 - 3y)dx + (3y^2 - 3x)dy$

解：$\frac{\partial z}{\partial x} = 3x^2 - 3y$，$\frac{\partial z}{\partial y} = 3y^2 - 3x$，故 $dz = (3x^2 - 3y)dx + (3y^2 - 3x)dy$。

8. 二重积分

  • (1) $\iint_D xy d\sigma = \frac{1}{24}$

解：$D: 0 \leq x \leq 1, x^2 \leq y \leq x$，$\int_0^1 \int_{x^2}^x xy dy dx = \int_0^1 \frac{x(x^2 - x^4)}{2} dx = \frac{1}{24}$。

  • (2) $\int_0^{\pi/2} \int_0^1 f(r\cos\theta, r\sin\theta) r dr d\theta$

解：$x^2 + y^2 \leq 1$ 在极坐标下为 $0 \leq r \leq 1$，$0 \leq \theta \leq 2\pi$；但第一象限为 $0 \leq \theta \leq \frac{\pi}{2}$。

附加题

  • $\int_0^1 e^{-x^2} dx \approx 1 - \frac{1}{3} + \frac{1}{10} = \frac{17}{30} \approx 0.567$

解：$e^{-x^2} = 1 - x^2 + \frac{x^4}{2!} - \cdots$，取前三项积分得 $\int_0^1 (1 - x^2 + \frac{x^4}{2}) dx = [x - \frac{x^3}{3} + \frac{x^5}{10}]_0^1 = 1 - \frac{1}{3} + \frac{1}{10} = \frac{17}{30}$。
