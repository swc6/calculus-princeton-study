填空题

  • $\int \frac{x}{1 + x^2} dx = $ __________
  • $\int e^{-x} dx = $ __________
  • $\int \frac{\sin \sqrt{x}}{\sqrt{x}} dx = $ __________

解答题

  • 求$\int (2x + 1)^5 dx$。
  • 求$\int \frac{1}{x \ln x} dx$。
  • 求$\int \sin^3 x \cos x dx$。
  • 求$\int \frac{e^{\sqrt{x}}}{\sqrt{x}} dx$。
  • 求$\int \frac{x}{\sqrt{1 - x^2}} dx$。
  • 求$\int \frac{\arctan x}{1 + x^2} dx$。
  • 求$\int \sec^2 x \tan x dx$。
  • 求$\int \frac{1}{x^2} e^{1/x} dx$。

填空题

  • $\int_0^1 \frac{x}{1 + x^2} dx = $ __________
  • $\int_0^{\pi/2} \cos^3 x \sin x dx = $ __________
  • $\int_0^2 \frac{1}{\sqrt{4 + x^2}} dx = $ __________

解答题

  • 计算$\int_0^1 (2x + 1)^3 dx$。
  • 计算$\int_0^{\pi/2} \sin 2x dx$。
  • 计算$\int_1^2 \frac{1}{x(\ln x)^2} dx$。
  • 计算$\int_0^a \sqrt{a^2 - x^2} dx$（$a > 0$）。
  • 计算$\int_0^1 \frac{x}{\sqrt{1 + x^2}} dx$。
  • 计算$\int_1^{\sqrt{3}} \frac{1}{x^2 \sqrt{1 + x^2}} dx$。
  • 计算$\int_2^4 \frac{\sqrt{x^2 - 4}}{x} dx$。
  • 计算$\int_0^{\pi/4} \tan^3 x \sec^2 x dx$。

综合应用题

  • 求$\int \frac{1}{\sqrt{e^x + 1}} dx$。
  • 求$\int \frac{x^3}{\sqrt{1 + x^2}} dx$。
  • 求$\int \frac{1}{x \sqrt{x^2 - a^2}} dx$（$a > 0$）。
  • 求$\int \frac{\sqrt{a^2 - x^2}}{x^2} dx$（$a > 0$）。
  • 求$\int \frac{x}{\sqrt{x^2 + 2x + 2}} dx$。
  • 计算$\int_0^{\pi/2} \cos^5 x dx$。
  • 计算$\int_{-a}^a \sqrt{a^2 - x^2} dx$（$a > 0$）。
  • 证明：$\int_0^{\pi/2} \sin^n x dx = \int_0^{\pi/2} \cos^n x dx$。
  • 求$\int \frac{1}{1 + e^x} dx$。
  • 求$\int \frac{x^2}{(x^2 + a^2)^{3/2}} dx$（$a > 0$）。
